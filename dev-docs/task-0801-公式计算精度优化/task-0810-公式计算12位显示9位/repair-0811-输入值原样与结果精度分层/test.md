## 主线审核判据

- AC-1~AC-12 每条至少一条用例，P0 不得 skip。
- 必须同时证明输入值“逐字保留”和公式结果“数值规整”，不能只做数值相等断言。
- 必须有真实 HTTP 保存草稿证据，不能只测私有 helper。
- 必须验证两个独立 scale 可分别变化，否则仅声明两个常量不算解耦。
