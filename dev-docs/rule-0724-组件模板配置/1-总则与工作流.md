## 1.2 🚨 每组件配置前必确认 4 项（禁止自己猜）

页签类型 / 料号列 / 料号名称列 / 行键 这 4 项是**猜不准、猜错要返工**的（实证：`来料` 曾被猜零件实为 BOM；`自制加工费` 料号曾绑 `finished_material_no` 实为 `code`），必须由用户明确。两条路：

- **有填好的 `组件模板.xlsx`（推荐）**：4 项已前置到模板列，直接读——`tabType`=Sheet B1；`partNoField`=勾「料号列」的字段；`partNameField`=勾「名称列」；`rowKeyFields`=勾「行键」的字段们；`sort_field`=勾「排序列」；`元素单价接价格策略`=勾「接价格策略」。**模板已填即照配，不再问。**
  - ⚠️ **「料号列」没勾 ≠ 留白待问**：多数客户模板本就不显示料号，这是**明确的「本页签无料号列」**，按 §1.3.1 配（`partNoField` 留空 + 名称列担标识 + 料号只进 SQL JOIN），**不要回头问用户、更不要自己造一列**。
- **没有模板 / 模板留白**：逐个组件用 `AskUserQuestion` 问用户勾选这 4 项（+ 排序列 / 接价格策略）。

> 模板列 ↔ 配置项对照见 `AGENT-配置入口.md §3`。

## 1.3 🔑 料号列铁律

### 1.3.1 模板没有料号列 = 正常，禁凭空造字段（2026-07-24 用户定）

**客户模板里不显示料号是真实业务场景**，不得为了填上 `partNoField` 而新增模板没有的可见字段（历史上曾给材料成本加「材质料号」、给外购件加「组成件料号」，已废止）。

| 情况 | `partNoField` | 标识由谁承担 | 料号去哪了 |
|---|---|---|---|
| 模板**有**料号列 | = 该字段（绑值按 §1.3.2） | `partNoField` | 既是可见列，也是 SQL JOIN 键 |
| 模板**没有**料号列 | **留空** | `partNameField`（名称列） | **只在 SQL 里做 JOIN 键**：`AS hf_part_no` 收窄本行、JOIN 取名称、`ORDER BY` 分组，**不出可见列** |

- 后端支持（`ComponentService.assertPartNoFieldRequirement`，2026-07-23 放宽）：`{材质元素,零件,外购件,主件}` 只要求**料号列或名称列至少一个**，两者皆空才 400。
- 类型判定支持（`QuotationTreeService`）：**优先 `partNoField` 取料号值，为空回落 `partNameField` 取名称值**做匹配标识。
- 代价（配置时心里有数）：无料号列时行键只能用名称等业务列（如 `["销售料号","组成件名称"]`），**同名多行会撞键**（editRows 塌缩）；真出现同名多行再回来跟用户确认要不要把料号列显出来。

### 1.3.2 模板确有料号列时 · 绑定值铁律

`partNoField` 绑的列**必须是该 `tabType` 语义层级的料号，禁绑成品/主件料号**。

| tabType | 料号列语义 | 应绑的列（V6） |
|---|---|---|
| 主件 | 成品/产品料号 | `material_master.material_no` |
| 材质元素 | 材质料号 | `element_bom_item.material_part_no` |
| 零件 | 组成件料号 | `material_bom_item.component_no`；`unit_price` 源取 **`code`**（非 `finished_material_no`=成品） |
| 外购件 | 外购组成件料号 | `material_bom_item.component_no`（OUTSOURCED） |

> 原因：`BomNodeTypeResolver` 把每个有类型页签 `partNoField` 取值收集为该类型候选料号；零件页签绑成成品料号 → 树把成品节点误判零件。
> `unit_price` 列语义：`code`=零件料号、`finished_material_no`=成品料号；常同值但语义不同（零件加工费上卷父成品时分叉）——按语义绑 `code`。

## 1.4 交付方式

- **API**（配置/调试）：`POST /auth/login` → `POST /component-directories` → `POST /components` → `POST /components/{cid}/sql-views` → `PUT /components/{cid}/driver-view`。
- **JSON 导入**（标准交付）：暂存目录建组件 → `GET /component-directories/{id}/export` → 用户建目录 → `POST /component-directories/{新id}/import/commit?conflictPolicy=RENAME`。
