# 前端任务分解 · 客户编号与客户 Excel 导入

> 前端只按本文件做；AC 原文见 [`需求文档.md`](./需求文档.md)，接口以 [`api.md`](./api.md) 为准。

## F-1 客户编号字段与唯一性错误

- 服务 AC-1~AC-6、AC-15。
- 在新增客户 Drawer 的基本信息区增加“客户编号”输入，标明“选填”；编辑态只读展示当前编号，不允许修改。
- 提交时展示后端 400/409 文案，不用前端自行判断唯一性。

## F-2 客户导入工具栏入口

- 服务 AC-7~AC-14。
- 在客户列表顶部工具栏增加“导入客户”按钮，与“新增客户”并列；使用 Drawer，不使用 Modal。
- Drawer 状态：上传态（下载模板/选择文件/开始导入）、成功摘要态、全量失败错误表态；导入中禁止关闭并显示原因 tooltip。
- 错误表至少展示 Excel 行号、列名、原因；成功后按 AC-8 文案刷新列表。

## F-3 客户导入 service 与类型

- 服务 AC-7~AC-14、AC-16。
- 新增下载模板与 multipart 导入调用；错误按 HTTP 状态和 `data.errors` 渲染，不按 message 猜测成功。

## F-4 前端回归与视觉还原

- 服务 AC-10、AC-16。
- 保持客户列表筛选、分页、编辑、停用和联系人维护行为；新建/导入入口符合 `docs/rules/frontend.md` 的 Drawer、工具栏、禁用态规范。
- 按 `原型图/` 逐屏还原，覆盖有数据、空文件、错误和导入中禁用态。
