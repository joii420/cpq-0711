# 后端任务

## B-1 数据库迁移与生产 SQL

- 新增 `template_customer` 表、组合主键、外键和匹配/反查索引。
- 编写 Flyway 迁移和 `deploy/db/update-261013-template-customer-many.sql`；脚本带事务、前置检查、幂等回填、后置校验，禁止破坏性 SQL。
- 实现前重新核对四方迁移最大版本；在隔离 PostgreSQL 16 数据库执行两次验证。
- 验收：AC-1、AC-13、AC-14。

## B-2 实体、DTO 与请求兼容

- 为模板增加客户关联读写模型；请求支持 `customerIds`，兼容旧 `customerId`。
- 多客户响应返回批量加载的客户摘要，保留兼容标量，不在 DTO 循环中查客户。
- 验收：AC-3、AC-10、AC-11。

## B-3 列表、匹配和核价查询

- 将模板列表的客户过滤、报价匹配、成本模板过滤、自动默认选择改为关联表判断。
- 保持专属/通用、`PUBLISHED`、产品分类、模板类型、排序和 `MIXED` 语义；使用 `EXISTS`/批量查询，锁定无 N+1。
- 验收：AC-2、AC-5、AC-6、AC-7。

## B-4 草稿复制、发布冻结与校验

- 创建新草稿复制全部客户关系；发布模板范围只读，更新接口拒绝直接修改发布/归档模板。
- 保存时去重、校验客户存在/权限；空范围表示通用。
- 验收：AC-4、AC-8、AC-9、AC-10。

## B-5 回归测试与契约证据

- 增加服务/资源层测试、迁移幂等检查、旧请求兼容测试和匹配规则回归测试。
- 用查询计数或 SQL 断言证明客户摘要无逐行查询；验证 `quotation.customer_template_id` 未改动。
- 验收：AC-1、AC-2、AC-5、AC-6、AC-11、AC-12、AC-14。

## 交付边界

后端不得修改报价单绑定、模板渲染快照或价格计算；任何发现需要改变匹配优先级/发布语义的情况先停在 Gate A/B 申请裁决。
