# 测试计划与 AC 追踪

## 测试分片

| 分片 | 范围 | 环境与边界 |
|---|---|---|
| S1 | 后端 API、服务、迁移 SQL | 独立 PostgreSQL 16 测试库/副本；允许写入任务前缀数据，不在共享开发库执行生产迁移；验证两次运行幂等和查询计数 |
| S2 | 前端单测、类型检查、构建、组件交互 | 私有前端进程；覆盖多选、回填、空态、发布禁用、旧字段兼容，不依赖共享后端 |
| S3 | 浏览器流程与视觉 | 单独测试数据前缀 `TMPCUST-261013-*`；禁止与其他 Playwright 会话并行，覆盖配置→发布→报价 A/B→列表筛选 |
| S0 | 主线回归 | S1/S2/S3 完成后执行，核对报价渲染、历史单、核价筛选和接口契约；不运行生产数据库写入 |

## 测试数据和安全

- S1 使用可回收的隔离库或数据库副本；不对共享库执行 `DROP`/`TRUNCATE`/批量删除。
- S3 数据使用唯一前缀，测试结束保留清单，不擅自删除共享数据。
- SQL 迁移验证只证明脚本可执行和结果可核对，不代表已在生产执行；生产执行须由发布流程单独授权。
- 失败证据保存命令、数据库版本、迁移版本、请求 payload、响应和截图，不用“接口 200”替代业务断言。

## Gate B 入口条件

所有 AC 均有唯一主证据分片；S1/S2/S3 通过后由主线执行 S0，补齐 `test-report.md`、主线亲验和生产脚本交付说明。
