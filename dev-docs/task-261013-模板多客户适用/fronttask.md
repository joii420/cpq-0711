# 前端任务

## F-1 原型与模板配置

- 先按 `原型图/` 确认配置页的多选、空态、已发布禁用态和最长客户名布局，再将单选改为多选。
- 保存/回填使用 `customerIds`；空选择显示“通用/所有客户”；旧接口标量兼容不改变页面判断。
- 验收：AC-3、AC-4、AC-8、AC-10。

## F-2 模板列表与创建入口

- 列表展示多个客户标签或“共 N 个”，支持按任一客户筛选；通用模板继续单独显示。
- 创建/编辑弹窗使用远程搜索多选，避免一次加载全部客户；保存错误按字段提示。
- 验收：AC-6、AC-10、AC-11。

## F-3 报价与核价模板选择

- 将报价创建中的 `t.customerId === customerId` 等单值判断统一改为关联客户集合判断，保留现有匹配接口、优先级、通用回退和 `MIXED` 展示。
- 核价模板筛选使用同一集合语义，不改核价规则。
- 验收：AC-5、AC-7、AC-8、AC-9。

## F-4 类型、服务与回归保护

- 更新 TypeScript 类型、API payload/response 映射和空值兼容；不改报价单模板绑定字段或渲染数据。
- 对多选重复值、空数组、接口 400、发布禁用态补充组件/交互测试。
- 验收：AC-10、AC-11、AC-12。

## F-5 页面视觉验收

- 按 `原型图/index.html` 逐屏检查默认态、搜索态、选中态、空态、错误态和禁用态；重点覆盖 1280 宽度和两个以上长客户名。
- 验收：AC-3、AC-4、AC-6、AC-8。
