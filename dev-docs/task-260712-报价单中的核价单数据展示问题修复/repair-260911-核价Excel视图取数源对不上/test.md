## 4. 已知不覆盖 / 已知语义

| 项 | 说明 |
|---|---|
| **每行显示同一个总计** | 表达式是 `[页签(总计)]` 且 `filterByNodeId` 原样保留 `subtotal` ⇒ 每个 BOM 节点行都显示整页签总计。**这是配置语义，不是缺陷**，🚫 不要当 bug 报，也不要在引擎里加特例 |
| 存量 `costing_excel_values` 是否自愈 | `ensure-excel-values` 只补 `IS NULL` 行 ⇒ **已算过的旧 0 值不会自动重算**。本次不处理；若测试中发现修好后页面仍 0，先确认是不是这个原因，**报主线，不要自行批量 UPDATE** |
| 核价 Excel **导出** | 走同一份数据，按数据源推断应一并恢复，但本次**不构造导出验证** |
| 前端 | 零改动，只做回归确认（见 `fronttask.md`） |
