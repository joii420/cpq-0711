**① R2 修复** — `CardEffectiveRows.java`，抽出私有纯函数 `readDecimal(JsonNode)`，`subtotal` 与 `subtotalByColumn` 两处都走它：

```java
private static BigDecimal readDecimal(JsonNode n) {
    if (n == null || n.isMissingNode() || n.isNull()) return null;   // 缺失/JSON null → null（原语义，未改）
    if (n.isNumber()) return n.decimalValue();                        // 数字 → 原行为
    String s = n.asText("").trim();
    if (s.isEmpty()) return BigDecimal.ZERO;                          // 空串 → ZERO
    try { return new BigDecimal(s); }                                 // 十进制字符串 → 本次修复点
    catch (NumberFormatException e) { return BigDecimal.ZERO; }       // 非法 → ZERO，绝不抛
}
```

字符串可读 ✅ / `subtotalByColumn` 一并处理 ✅ / 空串·非法·其它类型一律 `ZERO`、全路径不抛 ✅ / **写侧 `CardSnapshotService` 一行未动** ✅
