## 二、布局层：**一处结构性偏差 —— 判为原型缺陷，修原型不改代码**

| | 原型 `01` / `02` / `03` | 实现 |
|---|---|---|
| 列配置区形态 | **6 列表格**（来源列 / 字段名 / 字段类型 / 数据类型 / 角色 + 拖拽手柄） | **既有三栏面板**（可用字段 ｜ 已选输出列 ｜ 生成的 SQL），已选列为**卡片式行** |

**判定：原型缺陷（原型画错了既有页面的布局），🚫 不改代码。** 三条理由：

1. 三栏拖拽面板是 `task-260728` / `task-260819` 取数配置器建立的**既有布局**，本任务的范围是
   「在既有配置器里**加一个字段类型选择器**」，不是重画配置器。
2. 把三栏面板改成 6 列表格 = 重写整个取数配置器（含拖拽、可用字段树、实时 SQL 预览三块），
   **远超本任务范围**，且会破坏 `AC-39` 等既有回填契约。
3. 原型真正要传达的设计意图 —— **选择器 3 值、位置、文案、核价默认值、整列批量** ——
   在实现中**逐条对应且逐字一致**（见上表），设计意图零丢失。
