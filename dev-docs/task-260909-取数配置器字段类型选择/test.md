## §4 防假绿（本任务的具体形态）

| 风险 | 本任务的形态 | 防法 |
|---|---|---|
| **空验证** | AC-6 若两个页签**都渲不出值**，「逐字相同」会恒真 | **先断言两侧都非空**（行数 > 0 且至少一列有非空文本），再比对；`INPUT_*` 那侧是天然阳性对照 |
| **断言从未执行** | 选择器没渲染出来时，「选项恰好 3 项」可能读到空数组 | 先断言选择器存在且可展开，再数选项 |
| **测了旧代码** | 共享 dev server + 热重载 | 记录后端启动时间戳；用**行为探针**验明正身（传 `fieldType: "FORMULA"` 应 400 —— 旧代码会 200 并落库） |
| **判据本身零证据** | 探针端口/URL 写死导致输出自相矛盾 | 端口一律从环境变量推（`task-260909-核价树骨架` 的测试员栽过这一处） |
| **选择器坑** | antd 两字按钮插空格（「保 存」）、`Select` 虚拟滚动、`text=` 引擎不能混进 CSS 列表 | 沿用既有经验；timeout **先怀疑选择器再怀疑产品** |
