# 后端任务分解

## B1 数据模型与迁移

**服务 AC**：AC-1、AC-4、AC-5、AC-6、AC-7、AC-8、AC-9、AC-13、AC-14、AC-15、AC-16、AC-22、AC-31、AC-32、AC-36

- 新增计算输入快照、价格修订头/明细、投影头/行/diff、组成修订/明细、数据库预览 token、审批证据、调价命令、报价和核价绑定字段、状态约束、唯一键与查询/清理索引。
- 存量报价显式写 `LEGACY`，新单写 `SNAPSHOT`；不回填历史价格、不删旧缓存列。
- 数据库和应用层共同阻止 SEALED 修订修改/删除；幂等键和内容哈希防重复修订。
- 迁移号在实现 worktree 按四方规则重新实查，不在设计阶段预占。

## B2 价格修订与统一解析器

**服务 AC**：AC-1、AC-2、AC-3、AC-4、AC-5、AC-6、AC-7、AC-8、AC-9、AC-27、AC-28、AC-29、AC-30、AC-31、AC-32、AC-35、AC-36

- 实现完整修订复制、人工覆盖、显式调价、缺价补齐和新增元素解析；ACTIVE/DORMANT 从对应用户数据/投影的使用集合派生，不回写已封存修订。
- SNAPSHOT 的所有报价/核价行字段、公式、卡片、Excel 和导出只能通过绑定修订解析器取价。
- 策略、日历、行情、单位和汇率集合化批量读取；输出完整来源解释。
- LEGACY 进入显式旧适配器，不用空值猜测。

## B3 后端独立计算引擎

**服务 AC**：AC-2、AC-9、AC-10、AC-11、AC-12、AC-13、AC-14、AC-15、AC-16、AC-33、AC-35、AC-36

- 以持久化冻结输入构建计算上下文，独立生成四类结果、公式错误、行/单据合计与规范哈希。
- 独立实现 `CPQ-JCS-1` 的十进制字符串、空值、数组稳定键、RFC 8785 JCS、UTF-8 和输入/结果域隔离 SHA-256，并持久化协议版本；不复用前端上传结果或前端运行时代码。
- 与前端分别执行同一套规范字节/摘要黄金夹具；未知协议、稳定键缺失/重复或摘要格式非法均形成阻断错误，不按当前顺序兜底。
- 生成逐格差异；MISMATCH 永久阻断对应投影提交。

## B4 原子投影与异步任务

**服务 AC**：AC-10、AC-11、AC-12、AC-13、AC-14、AC-15、AC-16、AC-18、AC-19、AC-20、AC-21、AC-33、AC-34、AC-35、AC-36

- 先写不可见目标投影的全部行和头部合计，再以 CAS 检查目标指针/输入/修订/组成摘要并切活动指针。
- 过期任务标 `SUPERSEDED`；失败保留当前活动投影；重试不推进价格修订。
- 正式读、导出、提交和审批只读活动/冻结投影，不读未完成行。
- 提供阶段、耗时、失败码、重试次数和积压指标。

## B5 保存、提交、导出和价格调整接入

**服务 AC**：AC-3、AC-4、AC-5、AC-6、AC-7、AC-8、AC-9、AC-10、AC-11、AC-12、AC-13、AC-14、AC-15、AC-16、AC-32、AC-33、AC-34、AC-35、AC-36

- 产品/用户输入保存推进 `userDataVersion` 并创建目标投影；新增元素时先产生修订。
- 提交在单事务复核三条版本轴、用户版本对应的输入快照、所有阻断和 READY/MATCHED，再冻结输入快照/价格修订/投影并创建核价单。
- 导出使用冻结投影；后台 Excel 生成失败不得像现行兼容路径一样被吞掉后继续提交。
- 价格调整任务先创建价格修订，再重建两侧派生结果，禁止遍历散落 JSON 直接改格子。

## B6 财务审核、组成换版与审批

**服务 AC**：AC-17、AC-18、AC-19、AC-20、AC-21、AC-22、AC-33、AC-34、AC-36

- 核价详情返回报价提交和核价当前两组绑定、最终价格表与差异。
- 换版先无副作用预览，再用数据库摘要保存、30 分钟过期的一次性 token 加全部预期绑定确认；确认仅创建候选和异步操作，后台完成后以最终 CAS 一次激活。无新元素只推进核价投影，有新元素追加修订。
- 新修订或投影任一步失败时不切组成、价格或活动投影。
- 批准/驳回 CAS 校验所有绑定并冻结审核证据。

## B7 报价复制重构

**服务 AC**：AC-23、AC-24、AC-25、AC-26、AC-32、AC-33、AC-35、AC-36

- 新增不可变计算输入快照头/行、模板版本化输入 schema、应用校验和数据库不可变触发器；投影及报价当前/提交状态显式绑定快照 ID。
- 建立 `COPY_WITH_PRODUCT/RE_RESOLVE` 白名单：复制产品、用户输入和允许的来源事实，不复制客户范围事实、价格、金额、公式、派生、审批和核价事实；同模板也不得复制整份 `snapshot_rows`。
- 同模板复制生成目标单独立快照并重算；跨模板还需按目标 INPUT schema 映射。可补录缺失进入 `INCOMPLETE`，禁止复制/来源不明/黑名单载荷明确失败。
- 删除/替换现有 `ensureStructure` 异常吞掉并继续的行为；私有数据不可用时返回明确错误或可修复未完成态。
- 新单按客户和新 `priceBaseDate` 生成 R1/P1；缺价不继承源金额。

## B8 策略 v2、日期与 AI

**服务 AC**：AC-27、AC-28、AC-29、AC-30、AC-31、AC-35、AC-36

- 不可变策略/规则/日历版本、白名单条件 DSL、五种日期生成器、排除和统一缺价政策。
- 执行时解析覆盖完整区间的日历版本并冻结摘要；显式固定版本不完整则失败。
- AI 只做配置期编译，密钥走安全配置；发布前结构化校验，运行期执行器不依赖 AI。
- 试算与正式取价共用同一确定性执行器。

## B9 权限、审计、可观测性与保留

**服务 AC**：AC-3、AC-8、AC-17、AC-21、AC-22、AC-34、AC-35、AC-36

- 按权限矩阵校验销售改价、既有提交权限、财务换版/审批；不能只依赖前端隐藏按钮。
- 写不可篡改业务审计，保存原因和绑定摘要；日志脱敏。
- 实现平衡保留策略：正式生效或被复制/报价/核价/提交/审批引用的证据随单保留；仅从未激活且无引用的终态候选可在 90 天清重载荷、365 天清技术头，token/终态命令分别为 30/180 天。
- 清理器支持 dry-run、小批量事务和删除前二次绑定校验，记录策略/水位/数量/字节审计；部署配置只允许延长，后端不提供手工强删 API。
- 增加批量查询/任务耗时/差异率/失败率/队列积压监控。

## B10 交易日历与价格源绑定

**服务 AC**：AC-37、AC-38、AC-39、AC-40、AC-41、AC-42

- 新增日历主档、不可变版本和物化每日状态；实现草稿复制、整批导入、覆盖完整性、发布和引用保护。
- 日历选择器严格按固定版本/固定主档/价格源默认绑定解析唯一完整发布版，禁止周末或国家日历隐式兜底。
- 扩展价格源的默认日历和市场时区；已被价格修订引用的版本永久可读。
- 批量加载目标日期状态，禁止逐日查库；日历和策略发布检查复用正式执行器。

## B11 AI 解析配置与安全

**服务 AC**：AC-43、AC-44

- 新增 Provider/Profile、Prompt/Schema 不可变版本、Parser Release 和金标执行记录。
- 数据库仅保存 `secretRef`；专用安全客户端从 Secret/Vault 读取，DTO、日志、异常和导出统一脱敏。
- 发布 release 前强制金标全绿并保证唯一启用版本；禁用 AI 不影响结构化编辑或运行期取价。

## B12 投影任务监控

**服务 AC**：AC-45

- 提供投影任务分页、绑定/阶段/错误/diff 查询和严格条件重试。
- 后端不提供强制 READY、直接切指针或忽略 MISMATCH 接口；所有状态变化继续走投影状态机/CAS。
- 返回 90/365/30/180 天冻结基线、`everActivated/businessReferenced/payloadPurgedAt` 和排除原因；任何清理先排除曾激活、复制溯源、当前/目标/提交/核价/审批绑定，再记录清理审计。

## 后端完成定义

1. B1～B12 与 AC 双向映射无缺口，数据库、服务、接口契约测试通过。
2. 价格修订不可变、原子投影 CAS、提交/审批并发保护有真实 PostgreSQL 并发测试。
3. 复制、调价、换版和失败恢复均有端到端证据；LEGACY 回归通过。
4. SQL 查询计数或 tracing 证明不存在逐产品/逐元素 N+1。
5. 实现完成后更新架构基线、PRD 当前态和 `main-api.md`；未收到用户“打包/部署”指令时不生成部署产物。
