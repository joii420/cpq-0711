# 前端任务分解

## F1 报价单价格表与修订历史

**服务 AC**：AC-1、AC-3、AC-4、AC-5、AC-6、AC-7、AC-8、AC-9、AC-27、AC-28、AC-29、AC-30、AC-31、AC-34

- 在报价编辑页提供报价单级元素价格表 Drawer，显示修订号、基准日、来源、规范单位/CNY、报价币种值、涉及产品、ACTIVE/DORMANT、缺价与人工覆盖。
- DRAFT 且有权限时允许从统一入口批量改价并填写原因；产品卡片、公式字段和 Excel 单价只读。
- 保存携带用户数据版本和价格修订；409 时保留本地输入、展示服务端新版本摘要，禁止静默覆盖。
- 修订历史支持查看差异和来源证据，不提供修改/删除已封存修订。

## F2 前端计算、后端比对与差异

**服务 AC**：AC-10、AC-11、AC-12、AC-13、AC-14、AC-15、AC-16、AC-33、AC-36

- 用户编辑后立即按现有前端引擎预览，显式标记“待后端校验”。
- 独立实现 `CPQ-JCS-1`：规范十进制字符串、契约数组预排序、RFC 8785 JCS、UTF-8 和输入/结果域隔离 SHA-256；发送协议版本、输入/结果摘要和逐格值，并轮询或订阅后端投影状态。
- 执行语言无关黄金夹具并拒绝缺失/重复稳定键；不得复用后端运行时代码或现有局部 `stableStringify`。
- `MATCHED` 显示后端已确认；`MISMATCH` 展示逐格前端/后端差异并提供重新同步，不提供忽略按钮。
- 计算中/失败/过期时展示旧活动结果对应版本，提交始终禁用；不可把旧结果标为当前。
- 提交请求携带用户数据版本及其输入快照、价格修订和活动投影的全部预期绑定。

## F3 产品卡片与正式读取一致性

**服务 AC**：AC-2、AC-6、AC-7、AC-8、AC-9、AC-13、AC-16、AC-32

- SNAPSHOT 卡片统一展示价格表来源和只读锁；LEGACY 仍使用兼容展示。
- 报价/核价卡片及 Excel 预览都以服务端返回的活动投影为正式值，前端临时值只存在预览层。
- 删除产品后价格项显示 DORMANT 历史；重新加入展示复用说明。

## F4 财务核价审核页

**服务 AC**：AC-17、AC-21、AC-22、AC-33、AC-34

- 在现有 `CostingOrder` 详情增加“报价提交绑定”和“核价当前绑定”摘要。
- 展示报价冻结价格表、核价最终价格表及差异；Rc≠Rs 时突出核价新增元素，不能只显示一个含糊版本号。
- 批准/驳回携带所有预期绑定和审核版本；冲突后强制刷新预览。
- 销售查看时只读；换版和审批按钮按后端 `editable` 与权限共同控制。

## F5 组成版本切换

**服务 AC**：AC-18、AC-19、AC-20、AC-21、AC-33、AC-36

- 先调用 preview，展示部件变化、新增/休眠元素、是否会生成新价格修订、缺价和计算影响。
- 用户确认后用 `previewToken` 提交；处理中锁定重复操作。
- 无新元素明确显示“价格修订不变”；有新元素显示“旧元素保持、新元素按原基准日取价”。
- 失败后保持旧组成/价格/结果可见，展示可重试原因。

## F6 复制流程

**服务 AC**：AC-23、AC-24、AC-25、AC-26、AC-32、AC-36

- 复制确认文案固定为“复制产品内容并重新取价”，不提供复制价格/金额开关。
- 展示已复制与不复制项目，以及 `COPYING/REPRICING/CALCULATING/INCOMPLETE/READY/FAILED` 进度。
- `INCOMPLETE` 按稳定 input key 展示可补录项；禁止复制或来源不明的事实显示 `COPY_SOURCE_PRIVATE_DATA_UNAVAILABLE`，不得提供“仍然继续并填 0”。
- 缺价的新 DRAFT 可进入价格表补价；金额显示待计算，不能短暂闪现源单金额。
- 私有输入不可映射时展示明确错误和处理建议，不以 0 继续。

## F7 策略日期与 AI 配置

**服务 AC**：AC-27、AC-28、AC-29、AC-30、AC-31

- 按 `原型图/客户定价策略-统一日期表达式.html` 实现条件、日期生成器、排除、统一缺价政策、最终取价日历和来源映射。
- 周期采样统一使用 `PERIOD_POINT`；“属于/不属于”支持多选，区间使用起止值。
- AI 结果必须经结构化展示/确认；非 READY 禁止发布。页面明确“运行期不调用 AI”。

## F8 错误、空态、可访问性与视觉回归

**服务 AC**：AC-5、AC-9、AC-10、AC-11、AC-12、AC-20、AC-25、AC-26、AC-35、AC-36

- 覆盖默认、空元素、缺价、待确认、无权限、长元素名/长来源、计算中、差异、失败、过期和移动端状态。
- 对价格、状态、错误不能只靠颜色表达；表格和 Drawer 支持键盘与明确焦点。
- 大表使用分页/虚拟化或约定上限内的稳定渲染；禁止前端逐元素请求来源详情。

## F9 交易日历与价格源绑定

**服务 AC**：AC-37、AC-38、AC-39、AC-40、AC-41、AC-42

- 新增交易日历列表/详情，覆盖主档、版本、月历/列表编辑、Excel 导入导出、发布检查和版本 diff。
- 日历每日状态必须显示 OPEN/CLOSED、原因类型和来源；覆盖断档、重复日期及引用阻断提供可操作提示。
- 扩展价格源抽屉，维护默认交易日历和市场时区；策略页展示继承链、实际选中版本和覆盖范围。
- 发布版本只读；销售角色在策略试算中只读查看，不能显示可用但后端无权的动作。

## F10 AI 解析配置

**服务 AC**：AC-43、AC-44

- 系统管理新增 Provider/Profile、Prompt、Schema、Parser Release 与金标结果页签。
- Secret 只显示是否配置/引用名，绝不回填；连通性测试仅展示延迟和脱敏错误。
- 发布页显示金标通过/失败明细，存在失败时禁用发布；禁用解析 release 后结构化策略编辑仍可进入。

## F11 计算投影任务监控

**服务 AC**：AC-45

- 支持按报价/核价、scope、状态、错误码和时间查询，展示版本绑定、阶段、耗时、引擎和逐格 diff。
- 只有后端返回 `retryable=true` 时显示重试；不提供强制 READY、切指针、忽略差异或删除正式投影入口。
- 只读展示 90/365/30/180 天部署保留基线、投影是否曾激活/被正式引用、载荷是否已清理及排除原因；不提供手工清理入口。
