### AC-P3 · 两侧取价逐位相同 —— ✅ **本任务的核心成果**

UI 路径：核价侧拖入「元素单价」→ 预览客户选 `罗克韦尔（CUST-0001）` → 料号 `S-3120014539` → 重新执行。

```
结果条：返回 7 行 · 28ms
表头  ：["hf_part_no","production_no","material_part_no","element_code","元素单价","view_version"]
行1   ：3120014539 | 3120014539 | 00006 | Ag  | 43358.75 | 1     ← 与报价侧同值
行5   ：3120014539 | 3120014539 | 00168 | Cu  | 171.368  | 1
行2/3/4：                          ...   | NULL | 1
```

🔑 **43358.75 来自冻结版本**（`element_price_version_item`），**不是实时策略算出来的** ——
`CUST-0001` 的策略只配了「默认（AVG/1 周窗口）+ Cu（LATEST）」，而 `Ag` 最新行情是 `2026-08-09`、
落在窗口 `2026-09-02` 之外 ⇒ 实时策略对 Ag **算不出值**。
⇒ **核价侧只有走与报价侧完全相同的函数才拿得到这个数** —— 这正是 `A0-1` 不变量的全部意义，
也是候选方案「客户级元素价」被否决的实证理由。

截图：`证据/亲验/qy-13-AC-P3-预览结果表.png`
