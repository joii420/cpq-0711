## 🚩 代理提出、需主线裁决的 5 项（原文）

1. **「逐位相同」的口径需确认**：函数返回 `numeric(…,4)`（`12050.0000`），而 JSON 里存的是无尾零字符串（报价侧实测 `"11690"`）。代理按 **`::numeric` 数值相等**判定并同时打印两侧原始文本。若要**字符串逐字符相同**，T2.1 要改写 —— 按现状写死字符串比对**会必然红**。
2. **「本单建单日」有歧义**：`quotation_number = QT-20260910-0004` 但 `created_at = 2026-09-11 01:24:24 UTC`（= 本地 09-10）。代理实测 `2026-09-10` 与 `2026-09-11` 两个基准日**取价完全相同**，今天不影响结论；但代理**无法确认渲染时实际传入 `:priceBaseDate` 的是哪个日期**（那要读实现，它没读）。跨日或行情变动时这条可能变假红。
3. **T2.2/T2.3 的 UI 操作可能破坏「对 `QT-20260910-0004` 只读不写」的纪律**：本项目已知「打开报价单触发 autosave 风暴」，而 AC-1/AC-3 必须从编辑页进。代理的处理是加**副作用探针**（`row_version` / `card_snapshot_at` / `quote_values_at` / `md5(quote_card_values)` 前后对照），发现写入即**登记并报主线裁决**，不自行判 AC-4③ 失败、也不隐瞒。
4. **解锁执行时需要主线提供**：本分支临时后端端口 `PW_BACKEND_URL` + 临时前端端口 `PW_BASE_URL`。🚫 代理不会用共享 8081/5174。
5. ⚠️ **`e2e/global-setup.ts` 的账号解锁硬编码连 `cpq_db_0724`**，而本任务库是 `cpq_db_0910` —— 登录失败时可能表现为 timeout。代理会先按选择器/账号锁定排查，不误报成产品 bug。**既有测试基建问题，不属本次返修范围**，提前告知。
