## 3. 🚨 三条量具纪律（不满足别报绿）

### 3.1 AC-R5/R6/R7 的「零变化」断言必须先证明量具会动

三条都是「迁移前后 diff 为空 ⇒ 通过」。**空 diff 有两种成因**：真的没变，或者**两次都采到了空**。

**做法**（顺序不能反）：
1. 先采基准，**断言快照行数 > 0**（报价侧行键实测应有十几行）
2. **故意改一个核价侧角色** → 重采 → 确认 diff **有输出**（证明量具灵敏）
3. **回滚那次改动**，确认回到基准
4. 才开始正式的迁移前后对照

📌 本任务族出过这个假绿：`shell heredoc` 转义被吃掉产出两个**空文件**，`diff` 比出"相同"，打了 ✅。

### 3.2 AC-R1 断言「相邻」不是「存在」

🚫 写成「材料名在 fields 数组里存在」= **恒真**（改动前它也存在，只是在末尾）。
✅ 必须断言**下标关系**：`idx(材料名) === idx(最后一个 PART_NO 列) + 1`。

### 3.3 AC-R8 必须验「恰好 2 列」而不是「包含这 2 列」

🚫 「包含生产料号和工序编号」在改动前也成立（改动前是 3 列，包含这 2 个）。
✅ 断言**集合相等**：恰好 `{生产料号, 工序编号}`，且**不含**「模具台账/工装编号」。
