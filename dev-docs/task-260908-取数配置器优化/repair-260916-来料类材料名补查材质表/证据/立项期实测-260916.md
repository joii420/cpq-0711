## 5. COMP-0004 已落库的 sql_template（改动前）

```sql
SELECT
  dqiff.material_no AS hf_part_no,
  dqiff.material_no AS "_来料固定加工费_销售料号",
  dqiff.input_material_no AS "_来料固定加工费_投入料号",
  dqm.material_name AS "_物料_材料名",
  dqiff.item_seq AS "_来料固定加工费_项次",
  dqiff.base_value AS "_来料固定加工费_基准值"
FROM ds_quote_incoming_fixed_fee dqiff
  LEFT JOIN ds_quote_material dqm ON dqm.material_no = dqiff.input_material_no AND dqm.customer_no = dqiff.customer_no
WHERE dqiff.material_no = ANY(:total_material_no) AND dqiff.customer_no = :customerCode
ORDER BY dqiff.material_no, dqiff.input_material_no, dqiff.item_seq
```

对照 COMP-0002（物料BOM）材料名列：`COALESCE(dqm.material_name, mr.symbol) AS "_物料_材料名"` + `LEFT JOIN material_recipe mr ON mr.code = dqmb.input_material_no`。

## 6. 配置器保存的副作用（方案 A0 依据）

- `BuilderService.save`：写 `component_sql_view` 后，调 `componentService.update(componentId, compReq)`，其中 `compReq.fields` **只由取数配置列生成**（字段名 = 列的 `fieldName`）；随后对引用该组件的全部模板调 `templateService.forceRealignSnapshots(...)`。
- `BuilderRecompileService` 的重编译循环只调 `componentSqlViewService.update(...)`（改 `sql_template` / `declared_columns` / `required_variables`）+ 对齐 `builder_version` / `axisScope`，**不碰** `component.fields`；但入口 `refresh-all-snapshots` 恒处理**全部** builder 视图，并恒推模板两份快照。

COMP-0005 取数配置列名 vs 字段表：

```
builder_cols: 销售料号, 料号, 材料名, 项次, 要素名称, 费用, 比例（%）
fields      : 销售料号, 料号, 材料名, 项次, 要素,     费用, 比例
```

COMP-0002「物料」引用 COMP-0005（`source=57554055-…`）字段名的公式：来料回收费取值公式 / 来料财务费取值公式 / 来料损耗率取值公式（`predicate` 用「要素」、`targetExpr` 用「比例」）· 来料加工费取值公式（`targetExpr` 用「费用」）。
