## 3. 独立测试实现边界

- 测试工程师只读本任务 `需求文档.md`、`api.md`、`test.md`，以及 `cpq-backend/src/test/**`、`cpq-frontend/e2e/**`、现有测试配置和 package/pom；禁止读取 `cpq-backend/src/main/**`、`cpq-frontend/src/**` 及前后端实现 diff。
- 信息不足时只报告缺失契约，不得通过阅读实现补答案。
- 新测试命名统一 `T261027_RDP_`；后端建议放独立包 `com.cpq.task261027rdp`，前端定向单测/组件测试和 E2E 用同前缀标题。
- S-FLOW 创建四个私有角色账号和一张私有报价；不得修改现有 `admin/alice/bob` 的角色或密码。所有断言基于明确 ID/前缀，不使用“全库共有 N 行”。
- E2E 时间盒 30 分钟；超时即停并交回卡点、失败原文、已完成/未完成 AC，不无限重试选择器。新起 Vite/Quarkus 栈先预热目标页再计时。

## 4. 正向覆盖自检

- 四角色映射同时由纯函数（T-01/T-02）和真实会话页面（T-04/T-05）验证，避免只验实现函数。
- 页面全入口由 T-06 覆盖；服务端六类输出由 T-07 覆盖，前后端没有各自只验一半。
- 保存不变由 T-08 验证单次编辑序列，角色切换由 T-09 验证连续序列，均同时看响应、DB/快照和页面。
- 每条 AC 恰好属于 S-UNIT 或 S-FLOW 一片，无重无漏；每条均有 F-x/B-x 认领和测试编号。

## 5. 反向与边界覆盖自检

- 舍入半界、负数、尾零、零、显式位数比角色上限低/高均有断言。
- 原始输入、汇率、税率、利润和基础取数值有反向断言，防止“报价文件内所有数字一刀切”。
- 未登录 401、伪造角色无效、权限不扩大均有断言。
- 销售角色保存后不得把 4 位文本写回；换管理员必须恢复 9 位，防止格式化污染状态或缓存。
- 报价外默认 9 位和既有 2 位显示有回归断言，防止通用工具改造扩散。

## 6. 验证命令与证据

- 前端：`npx tsc -b`、新增定向 Vitest/组件测试、既有 precision/formatNumber/ComponentCell/Excel/比对测试、生产构建、定向 Playwright。
- 后端：新增角色策略/格式化/输出测试，既有 `NumberFormatUtilTest`、`QuotationOutputPrecisionHttpContractTest`、`ExcelViewServicePrecisionTest`、`ComparisonExportServiceTest`、`QuotationEmailPrecisionTest`，再执行构建和报价相关回归。
- xlsx 使用 Apache POI/Node xlsx 解析真实单元格文本，不以文件大小或下载成功代替精度断言；HTML 解析目标数字文本；邮件使用测试 Mailer 捕获附件。
- 保存不变记录请求前后 JSON 原文、数据库十进制值、快照摘要和 `updated_at`；输出操作记录 HTTP 状态、角色、目标文本。
- 所有命令、测试数量、实际值、失败/未验证项原样写入 `test-report.md`；测试完成后由主线清产物重跑并亲验。
