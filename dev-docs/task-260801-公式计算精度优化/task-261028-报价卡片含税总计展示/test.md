## 4. 正向覆盖自检

- 默认 13% 精确值同时由纯函数/SSR（T-01）和真实编辑/详情页（T-04）覆盖，不只验内部函数。
- 4/9 位精度、`HALF_UP` 与去尾零由 T-02 精确断言，真实页面复用前序任务已实现的角色上限。
- 编辑/只读两个独立渲染入口由同一连续导航用例覆盖；保存链由 T-05 单独覆盖。
- 每条 AC 恰好属于 S-UNIT 或 S-FLOW 一片，无重无漏；每条均有 F-x/B-x 认领和测试编号。

## 5. 反向与边界覆盖自检

- VAT 0%、百分比回退、ratio 优先、缺失、非数字、负数和 >100% 全部有硬断言，避免静默伪造含税价。
- 核价编辑/只读分支明确断言 `(VAT)` 为 0，防止共享 CSS/组件扩散到核价。
- 保存用例同时断言“没有新字段”和原 decimal string/快照不变，防止显示值污染业务 state。
- 窄屏和最长值用几何断言与截图双证，不以“截图看起来可以”代替溢出断言。
- 已知 `quotation-flow.spec.ts` 四条失败由 `DEC-0008` 约束，不能作为结论证据；若执行只做 master/分支同型背靠背 A/B，新增失败数必须为 0。

- 前端：`npx tsc -b`、本任务定向 Vitest、相关精度/产品小计存量测试、`npm run build`、任务专项 Playwright。
- 渲染证据：每个目标先断言卡片/总计行数再比文本，防止空集合假绿；保存 1280 和 390 视口截图。
