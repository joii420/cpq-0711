## 4. 规避掉的坑
- **公平信号量的无参 `tryAcquire()` 同样会插队**：一律用 `tryAcquire(0, ms)` 再 `acquire()`。
- **协调线程与工作线程分池**：只把原池换成定长池会让「join 工作线程的协调线程」占满线程而饿死工作线程；本轮协调线程在 `coordinatorPool`，名额只限「试算那一段」，协调线程从不持名额。
- **单版本无回归**：名额数 = 单版本工作线程数，所以只有一个版本时一个都不用等（AC-14 的结构不变）。
- **测试会覆盖别的任务的证据文件**：`fingerprint-branch.json` 第二次被覆盖，已按 HEAD 还原。
