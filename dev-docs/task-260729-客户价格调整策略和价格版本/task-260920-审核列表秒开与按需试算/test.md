## 5. 两条最容易出假绿的地方

### 5.1 `AC-13` 不许只比两次并行

2026-06-22 那次竞态**单跑与单测都看不出来**；而两次并行可能碰巧都对，也可能错法相同。所以必须同时满足：两次并行互相一致（抓非确定错误）+ 与**冷缓存串行重算**的参照一致（抓确定性错误）+ 输入指纹一致（排除「数据本身变了」）+ 阳性对照（证明哈希能抓到差异）。

v2.1 补的两个坑（评审二轮【2】【3】）：① 「重算」会**覆盖**原值，串行参照必须和**重算之前导出的**值比，和库里的当前值比等于自己比自己；② 每跑一轮，不进池料号的指针都会被推到本轮版本，指纹若把它们算进去，按定义就不相等 —— 指针只比进池料号，元素价按内容比。另外 73% 的行两侧全空，随机抽样要从「有值」的行里抽，否则大部分样本没有鉴别力。

### 5.2 `AC-14` 不看绝对值，看结构

同一段代码在不同负载下单次试算差 2.4 倍（297 ms vs 695~737 ms），拿绝对分钟数判通过等于判负载。所以断言用**同一轮内**的比值（全量 vs **耗时最长的那一组**），绝对值只记录不判。v2 另有一条「组耗时和 ÷ 全量 ≥ 2.0」已删：按当前数据的组规模，它的理论上限只有约 2.2~2.3，正确实现也只剩 10~15% 余量（评审二轮【13】）。计时轮必须是**冷启动后的第一轮**（R1）。
