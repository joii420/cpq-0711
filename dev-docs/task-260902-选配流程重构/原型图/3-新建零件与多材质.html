维度是否进指纹实测依据
工序顺序❌ 不进 ["Z100","Z101"].sort() === ["Z101","Z100"].sort() → "Z100,Z101"
工序重复次数✅ 仍进 ["Z100","Z101","Z100"].sort() → "Z100,Z100,Z101" ≠ "Z100,Z101"
🚫 调序的 ↑↓ 不因此取消 —— 它影响工序在报价单里的显示顺序与落 unit_price 时的 seq_no，只是不影响料号复用判定。这是两件事。
🚨 「重复次数仍进指纹」是防错重点：sort() 不去重，所以「焊两次」与「焊一次」是不同料号（AC-20）。 实现者若在 sorted() 旁顺手加一个 distinct()，这条行为会被静默抹平 —— 而它没有任何报错外观，只表现为两个不同工艺的产品共用了价格。
