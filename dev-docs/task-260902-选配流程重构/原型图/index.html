这次改的是什么

一句话：选配从两层模型升到三层。

现状（两层） 本次（三层） 产品 产品（客户产品编号 ← 前置到第一步） └── 配件 ＝ 一个材质料号 └── 配件 1..N ├── 材质（单个） ├── 零件（新建 / 已有） ├── 元素含量 │ ├── 品名 / 规格 / 尺寸 / 总重 └── 工序 │ ├── 材质 1..N（各带占比，Σ=100%） │ │ └── 含量配置（标准配方 / 自定义） │ └── 工序 └── 外购件（从料号库选） └── 工序 └── 组合工序
证据：现状「配件」确实就等于一个材质料号 —— PartRequest.recipeCode 是单值；前端提示语原文是「请至少新增一个材质料号」（ConfigureProductDrawer.tsx:271）；落库只写 1 行「自指物料行」。

原型清单（6 份）

按流程顺序。每份内含多个状态，标题里标了对应 AC。

步骤 1
客户产品编号
编号前置到第一步。已存在则挡住，引导改走「从产品库添加」。
默认已存在阻止禁用态最长文案
步骤 2
添加配件 · 类型分流
新增的中间层：先选零件 / 外购件，零件再选新建 / 已有。
空态类型选择来源选择多配件列表
步骤 2a · 🔥 核心页
新建零件 + 多材质占比
品名/规格/尺寸/总重 + 可搜索的材质选择器 + 挂 1~N 个材质、各填占比、各选含量配置。
默认材质选择器过滤/无匹配合计≠100%自定义含量禁用态12位小数证伪对照组材质去重
步骤 2b
已有零件 + 工序
从产品列表选，材质构成沿用它自己的，只选工序。最接近现状。
默认搜索无结果禁用态
步骤 2c · 🆕 全新
外购件 + 工序
从 material_type='外购件' 的料号里选。空态是上线第一天最可能看到的画面。
默认(1条)空态禁用态最长文案
步骤 3-4
组合工序 + 指纹比对
提交前按指纹比对：命中则带出销售产品信息复用料号，未命中则新建。
组合工序未命中→新建命中→复用提交失败
