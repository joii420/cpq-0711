步骤 2 · 添加配件 → 选择配件类型

这一层是本次重构新增的。现状没有「配件类型」概念，「配件」直接等于一个材质料号。

ℹ
三层模型的中间层：产品 → 配件（零件 / 外购件） → 零件挂 1~N 个材质 → 每个材质选含量配置。
实测：material_bom_item 的 characteristic 三态里 OUTSOURCED 零行（全表 RECIPE 11095 / ASSEMBLY 49）—— 外购件是从未落地过的能力，不是「已有但没接」。

状态 B · 选择配件类型（零件 / 外购件）

点「添加配件」后的第一个岔路。两个选项都常用，所以并排展示而不是下拉。

添加配件 · 第 1 步：选择类型
🔩
零件
本厂加工的零件。可以新建，也可以引用已有零件。
零件下面挂 1~N 个材质，每个材质填占比。
🛒
外购件
从供应商采购的成品件，不含材质构成。
从现有料号库里选，再选它的工序。

状态 C · 零件来源（新建 / 已有）

选了「零件」之后的第二个岔路。选「新建零件」进原型 3，选「已有零件」进原型 4。

添加配件 · 第 2 步：零件来源
✨
新建零件
填品名 / 规格 / 尺寸 / 总重，再挂材质。
适用于这个客户产品特有的零件。
📚
已有零件
从产品列表里选一个已存在的零件，只需再选工序。
材质构成沿用它自己的，不重新配。

状态 D · 已加多个配件（默认态）有数据

配了 2 个零件 + 1 个外购件。配件卡片直接显示它的构成摘要，不用展开就能核对。
