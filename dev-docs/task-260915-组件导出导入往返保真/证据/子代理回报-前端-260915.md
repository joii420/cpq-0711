1. **没有复用 `unresolvableBlock`**。`:174` 那个 `UNRESOLVABLE` 会拦提交，新字段的同名值绝不拦 —— 新逻辑完全隔离在 `planColumns` 的 render 里，`canSubmit` 一行未动，两处写死警示注释防后人回灌。

3. **没把 `node_modules` 整目录软链过来**。那样 `tsc -b` 的 `.tsbuildinfo` 会写进主仓共享缓存，可能给主仓留下外来增量状态。
4. **没拿 5174 验证**（那是主仓代码 = 假绿），用 5198 并在验证后确认已停、5174 仍 200。
5. **没在前端给 `builderCoord` 兜底掩盖**：后端缺字段时显示 `—`（等同 `NOT_BUILDER`），不伪造 `RESOLVED`，缺陷在亲验时仍看得见。
