## ① 背景与目标

现有材质导入会自动补建元素，导致“导入材质”同时修改元素基础数据，职责边界不清；元素管理又缺少独立批量导入、导出入口。目标是把两类主数据彻底解耦：元素先维护，材质只引用；两类编号均由系统发号；同一材质允许追加不同含量配置，但元素组成保持不变。

## ② 范围

### 本期做

1. 材质库导入/导出只处理 `material_recipe`、材质组成、含量配置及配置元素，不增删改 `element`。
2. 元素页新增导入、导出和模板下载；模板仅含“元素符号、中文名称”且带一行示例；元素编号由系统发号。
3. 元素导入遇到已存在符号时只覆盖中文名称；不改变元素编号、符号和状态。新元素默认启用。
4. 材质模板/导出仅含“材质、组号、元素符号、含量”，模板带一行示例；不含材质编号、含量配置编号、状态等系统字段。
5. Excel 组号仅用于文件内分组，不原样入库。真正新增含量配置时，系统按该材质历史最大组号继续发号并拼接配置编号，停用配置占用的号码不回收。
6. 材质导入先完成整份文件校验：缺失或停用元素、既有材质元素组成不一致时，聚合全部问题并整份回滚。
7. 同材质、同元素组成、同含量的启用配置重复导入时跳过；含量不同则新增配置。

### 本期明确不做

1. 不自动启用停用元素；用户须在元素管理中显式启用。
2. 不通过元素导入修改元素符号、编号或状态。
3. 不清理历史脏编号；自动发号仅统计纯数字编号。
4. 不删除旧接口；在兼容期内只调整既有材质导入/导出内容，并新增元素批量接口。

## ③ 验收标准

### 单点 AC

- **AC-1**：元素模板下载后只有“元素符号、中文名称”两列且有一行示例，不含元素编号；导入新符号后系统生成下一纯数字元素编号，状态为启用。
- **AC-2**：元素库已有 `Ag / 银` 时导入 `Ag / 白银`，完成后仅中文名称变为“白银”，元素编号、符号、状态均不变。
- **AC-3**：元素导出文件包含元素编号、元素符号、中文名称、状态，导出不产生数据库写入。
- **AC-4**：材质模板下载后只有“材质、组号、元素符号、含量”四列且只有一行示例；材质导出也只有这四列，不含材质编号、配置编号和状态。
- **AC-5**：材质文件引用一个不存在元素和一个停用元素时，接口一次返回两者清单；本次文件涉及的材质、组成和配置新增数均为 0，元素表也无写入。
- **AC-6**：既有材质元素组成 `{Ag, Ni}`，文件导入 `{Ag, Cu}` 时返回组成不一致详情并整份失败；即使文件中另一个材质完全合法，也不得部分落库。
- **AC-7**：既有材质 `{Ag, Ni}` 已有启用配置 90/10，导入同含量时跳过；导入 85/15 时新增一条配置，配置编号按数据库历史最大组号 + 1 生成。
- **AC-8**：Excel 将组号从 `1` 改成 `A` 但行内容不变，导入结果仍按内容判重；Excel 组号不作为数据库组号保存。
- **AC-9**：已有最大数据库组号对应的配置已停用，再导入新含量时仍使用“全部状态最大组号 + 1”，不回收旧号。

### 序列 AC

- **AC-10**：先在元素页导入新元素并刷新列表，再在材质页导入引用该元素的文件，导入成功；刷新页面后材质和配置仍存在。将该元素停用后再导入一个新材质，整份失败并提示该元素已停用。
- **AC-11**：同一份材质文件连续导入两次，第一次按需新增，第二次材质新增数和配置新增数均为 0；切换页面再返回、刷新浏览器后结果不变。

### 边界 AC

- **AC-12**：元素文件内同一符号出现两个不同中文名称时，整份失败并指出冲突行，不采用“最后一行覆盖”；数据库无部分写入。
- **AC-13**：空文件、缺列、非法含量、同组重复元素或组内含量和不满足既有规则时返回明确错误，不抛 500；本次新增为 0。
- **AC-14**：未授权请求元素或材质导入/导出接口时沿用现有鉴权结果，不绕过权限。

## ④ 依赖与影响面

- 后端：`ElementResource`、元素服务、`MaterialRecipeImportService`、`MaterialRecipeExportService`、配置发号服务与实体。
- 数据库：为含量配置增加独立数据库组号，历史数据由现有 `seq` 回填；保留 `seq` 作为创建顺序/不回收水位。
- 前端：元素管理工具栏与导入 Drawer；材质导入 Drawer 的说明、统计和整体失败详情；两类 service。
- 回归：材质手工新建配置、停用后再新建、材质列表导出、元素 CRUD、旧材质模板拒绝路径。
- 不改变金额公式、报价业务或权限模型；触及跨端导入导出契约与 DB 迁移，按标准档执行。

> “导入材质时,如果材质引用的元素不存在,整组导入失败,并且提示所有不存在的元素列表,让用户先去创建好需要用到的元素。”

> “同一个材质下,元素组成必须相同,如果后导入的数据元素组成与已存在的材质元素组成不同,提示错误,整组excel导入失败。”

> “元素编号自动发号,用户无需填写”“停用不可用于新材质”“材质编号也由系统自动发号,含量配置编号也有系统根据组号自动拼接,excel中不需要有该字段”“下载的导入模板中给一行数据示例”。

> “组号只在excel中声明同组，含量不同时自动创建新的组号入库。”
