# 附录 · 三套数据集字段矩阵（建表唯一依据）

> 由 `scratchpad/gen_matrix.py` 从三份 Excel 机器生成。**改 Excel 必须重跑本脚本并更新本文件**。

> 底色语义：🔴 红 `FFFF0000` = 必填建字段 · ⚪ 白/无填充 `theme0` = **不建字段**（主数据 JOIN 展示列）· 🟡 其余色 = 选填建字段。

> 轴列**无论底色一律必填**（闸门 A0 裁决）。
