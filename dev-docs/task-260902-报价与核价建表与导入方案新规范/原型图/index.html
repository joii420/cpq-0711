「详细核价」页签为什么没有单独原型

它与「基础核价」逐像素同构，唯一差异是抽屉左侧 tab 由 9 个变为 17 个（多出 产能 / 设备折旧成本 / 生产设备能耗 / 辅助设备能耗 / 模具工装成本 / 生产耗材BOM / 包装材料BOM / 电镀成本）， 且 tab 数由 GET /dataset/{dataset}/sheets 返回决定、前端不写死。 再画一份完全相同的图只会制造两份需要同步维护的基准。

还原纪律

  • 视觉基准是原型图，不是审美 —— 布局结构、控件类型与顺序、文案、空态与禁用态文案逐项对齐
  • 允许的偏差只有一类：组件库能力所限的等价实现，且必须在回报里列出
  • 🚫 原型没画到的地方不许自由发挥 —— 停下来问，那是需求缺口
  • 🚨 原型与 AC 冲突时以 AC 为准，并立即报告
