还原纪律 —— 抽屉三条
1. 🔑 客户号取自被点击的行，不是壳页选择器的当前值。 在「所有客户」态下选择器是空值， 而行自身携带确定的客户号 —— 取错会让抽屉在「所有客户」下退化成混行。
2. overview / rows / versions 三个请求全部带 customerNo，过滤口径必须一致。
3. 🚨 版本下拉只列该客户的版本。版本号按 (customer_no, 销售料号) 各自独立递增， 混排会让用户看到一个不存在的版本序列。
生产料号编辑（F-6）：保存时恒传该行的 customerNo；后端对「命中多行」会报错， 前端要如实展示该错误，🚫 不许吞掉或改写成「保存成功」。
