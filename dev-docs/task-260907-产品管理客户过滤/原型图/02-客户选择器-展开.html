还原纪律
1. 分组顺序固定：所有客户 → 已建档（按编号升序）→ 未建档（按编号升序，置尾）。
2. 未建档项必须可见且可选，标记文案「未建档」，配色 #d46b08。 🚫 不得因 customerName 为 null 就把它筛掉 —— 那等于把后端特意带出来的候选又丢一遍。
3. 搜索匹配编号与名称两者（antd showSearch + 自定义 filterOption）。 未建档项没有名称，靠编号也要能搜到。
4. 「暂无产品」标记是可选增强，若实现成本高可省略；但该客户必须出现在候选里（这是并集口径的意义所在）。
5. 候选端点失败（404 / 500）时的降级：候选只剩「所有客户」一项，列表照常可用。 🚫 不做任何 mock 兜底 —— 塞 mock 会把「后端没就绪」伪装成「这个客户真的没有产品」。
