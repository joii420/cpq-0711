还原纪律 —— 四条
1. 🚨 rowKey = `${customerNo}|${axisValue}`。这是本屏最容易漏、症状最像「玄学 bug」的一处。
2. 客户两列置于最左，因为它们现在是行身份的一部分，不是附属信息。
3. customerName 为 null 时渲染 —（不是空白）。它来自后端同一条 SELECT 的 LEFT JOIN customer，🚫 前端不得逐行去查。
4. 「所有客户」下不去重：同料号跨客户的多行都要展示。去重会让用户以为只有一个客户配了这个料号。
本次不动的：客户列不支持点击排序（后端 sortBy 白名单本次不新增键）；生产料号列的可编辑行为不变（见图 04）。
