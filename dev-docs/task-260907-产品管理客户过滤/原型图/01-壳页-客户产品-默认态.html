还原纪律 —— 三处最容易做错的地方
1. 选择器必须在标题行，不许放回页签内部（放回去就退化成页签级私有状态，AC-9 不成立）。
2. 「所有客户」这一项的 value 用空串而非 undefined —— antd Select 拿到 undefined 会显示 placeholder 而不是选项文案（这是本项目已踩过的坑）。发请求时再转回 undefined。
3. 未建档客户（C1 / Q13CUST0617）的行照常展示，客户名称列渲染 —。 🚫 不得因 customerName 为空而把行或候选项过滤掉。
