已确认规则
产品有效税率优先于报价单税率；没有产品税率才使用报价单税率。
快照规则
报价行保存 VAT 快照，修改价格重新计算仍使用快照，系统税率变更不回溯。
计算规则
含税单价 = 元素单价 × (1 + [增值税])，结果写入现有 BOM 含税单价列。
