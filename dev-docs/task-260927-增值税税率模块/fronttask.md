# 前端任务分解（闸门 A 草案）

> 原型基准：`原型图/` 下已获认可的 9 个页面；全部为现有页面局部增量，不新增“导入销售产品”页面或报价行更换按钮。

## F-1 税务分类与版本管理（服务 AC-8、边界权限）

1. 在现有系统配置入口接入[税务分类与税率管理.html]，保持现有列表、抽屉、工具栏和权限可见性。
2. 支持分类列表、默认分类标记、版本历史、生效/失效日期、启停和新增版本；已引用版本隐藏物理删除或显示不可删除原因。
3. 表单展示百分比；提交字符串百分比；前端校验范围、日期区间和冲突错误，最终以 API 错误为准。
4. 默认分类切换使用确认提示，成功后刷新列表和报价创建默认值，不刷新历史报价。

## F-2 客户默认 VAT（服务 AC-1、AC-8、边界权限）

1. 在现有 `CustomerManagement.tsx` 编辑抽屉增加“默认 VAT”字段，位置和样式以[客户管理-默认VAT.html]为准。
2. 列表/详情显示“未设置”与 `0%` 的区别；说明文案固定为“仅用于报价默认值/兜底，不代表客户固定税率”。
3. 客户 Excel 模板列与导入预览错误沿用现有客户导入流程；不新增独立导入入口。

## F-3 产品管理销售/客户产品税务分类（服务 AC-1、AC-2、AC-8）

1. `ProductSalesPartTab` / `ProductSalesPartDrawer` 在现有销售产品入口展示税务分类、当前有效 VAT 和未设置状态，编辑动作在原抽屉内完成。
2. `ProductCustomerPartTab` 增加只读税务分类列，来源为同一销售产品绑定；关联不到时显示“未设置”，不得显示客户默认 VAT。
3. 不增加“导入销售产品”按钮；产品导入仍从报价单管理现有“从基础数据导入”进入。
4. 客户切换、分页、搜索和抽屉重新打开时，税务字段必须随 `(customerNo, materialNo)` 重新加载，禁止复用其它客户缓存。

## F-4 报价创建与 Step2 快照（服务 AC-1、AC-2、AC-5、AC-6、AC-7）

1. 在真实 `QuotationWizard` Step1 的现有基本信息区域增加报价默认 VAT 与来源提示，不把页面改画成汇总表；以[报价创建-默认VAT与快照.html]为准。
2. Step2 现有产品卡片头部/页签/BOM 布局保持不变，在[报价编辑-Step2-税率快照.html]指定位置增加税务分类、来源、VAT 快照、含税金额信息。
3. 产品有效税率优先时显示“产品税务分类”；否则显示“报价单默认”；默认分类兜底显示“系统默认税务分类”。
4. 重新计算、价格数量编辑、切换页签、刷新页面后继续显示同一行快照；不得增加“更换产品”按钮。删除后从现有添加产品入口添加的新行显示新快照。
5. 报价单同时含 13% 与 6% 行时，每行独立显示税率和含税结果，不能把报价头默认 VAT 覆盖所有行。

## F-5 现有“从基础数据导入”预览（服务 AC-9、AC-10）

1. 在报价单管理现有导入抽屉增加税务分类列/状态；空分类行显示默认分类和“受影响 N 行”。
2. 未知分类编码显示 Excel 行号、列名、编码和整批拒绝状态；确认按钮在预校验失败时禁用。
3. 成功确认后沿用现有导入/物化流程，不新增独立导入按钮，不在产品管理页面复制导入逻辑。

## F-6 公式标签与含税单价策略（服务 AC-3、AC-4、AC-11）

1. 公式编辑器默认标签区增加 `[增值税]`，插入后 token 使用 `vat_rate`；标签值说明为“比例值，例如 13% = 0.13”。
2. 用户不插入标签时，系统不自动给价格或金额加税；已有公式行为不变。
3. 在现有组件管理物料与元素 BOM 的价格策略列增加“含税单价”可选策略，覆盖 QUOTE/基础核价/明细核价，不单独创建新页面。
4. 无报价行快照的预览/核价结果显示“待报价税率”，不能显示当前系统税率数值；若公式因此无法得出金额，显示状态而不是 0 元伪结果。

## F-7 前端数据与精度协议（服务 AC-3、AC-4、AC-5）

1. VAT 比例、金额计算使用现有 decimal 工具，禁止新增 `number` 直接乘法作为最终金额来源。
2. 前端公式序列化、公式上下文、`computeAllFormulas`、`buildLineItemEvalContext`、只读卡片和 Excel 视图全部传递 `vatRateRatio`。
3. 含税单价计算保留内部精度，展示沿用元素价格 9 位上限和现有金额显示规则；前后端同一输入必须相同结果。
4. 任何缓存 key/状态 key 包含报价行 ID 或快照版本，不能因同一料号在不同报价中共享 VAT 状态。

## F-8 前端完成定义

- 9 份认可原型对应真实入口逐屏实现；无虚构按钮/路由。
- `tsc`、前端单测、公式 token 对拍和 1440/1280 两视口冒烟通过。
- 产品管理客户/销售两列表展示同一绑定来源；Step2 删除+添加、重算和刷新均保留快照。
- 受影响组件按 AP-44 / AP-50 双视图协议同步检查，不能只改报价编辑页。

**AC 追溯**：F-1~F-7 合计覆盖 AC-1 至 AC-12；AC-12 的历史报价打开由只读 DTO/渲染回归验证，不改写存量字段。
