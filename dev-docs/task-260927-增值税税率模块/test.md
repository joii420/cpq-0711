# VAT 测试方案与 AC 可追溯矩阵（闸门 A 草案）

> 本文件是测试契约；执行结果见同目录 `test-report.md`。测试分片按写入面划分，避免多个测试片同时改同一报价/产品夹具。

## 1. 分片与写入面

| 分片 | 写入面 | 责任范围 |
|---|---|---|
| S-DB | 专用测试库迁移/回滚检查；私有前缀分类、版本、产品、报价夹具 | migration、约束、默认种子、无存量回填 |
| S-API | REST 端点与权限；每个测试使用唯一前缀数据 | 分类/版本 CRUD、客户默认、产品绑定、导入预校验、报价 DTO |
| S-BE | Java 单元/服务集成；内存或专用库夹具 | VAT 解析、快照不可变、重算、公式 token、精度和版本边界 |
| S-FE | 前端单元/组件 | token 插入、上下文、金额计算、表格状态和缓存 key |
| S-UI | 离线原型/临时前后端只读冒烟；不与写库片并行 | 9 个真实入口、1440/1280、导入错误/成功、Step2 删除+添加与重算展示 |

同一报价单/产品绑定的写库测试只能由一个分片持有；S-UI 不执行提交、导入或分类修改。E2E 启动前按项目规则采样确认没有其它 Playwright 进程。

## 2. 核心测试场景

### S-DB / S-API

1. 空库迁移后存在且仅存在一个默认分类 `GENERAL_GOODS`，存在 13% 有效版本；重复迁移不覆盖用户改名/改版本。
2. 同分类重叠版本被 409 拒绝；相邻 `[from,to)` 版本可保存；`effectiveTo <= effectiveFrom`、税率小于 0/大于 100 被拒绝。
3. 已被报价行引用的版本不可物理删除/改税率；新增版本可用于未来报价。
4. 客户 `defaultVatRate=null` 与 `0` 分别返回未设置/0%；超范围被拒绝；导入任一错误整份零写入。
5. 产品按 `(customer_no,material_no)` 写分类；同料号不同客户互不串值；客户产品列表只读 JOIN，缺关联显示未设置。
6. 未知分类编码导入返回 Excel 行号、列名、编码，所有产品均不落库。

### S-BE VAT 解析与快照

1. 产品有效 13% + 报价默认 13% → 行快照 13%，来源 `PRODUCT_CATEGORY`。
2. 产品有效 6% + 报价默认 13% → 行快照 6%，来源 `PRODUCT_CATEGORY`。
3. 产品无分类/无有效版本 + 报价默认 9% → 行快照 9%，来源 `QUOTATION_DEFAULT`。
4. 产品无分类 + 报价默认为空 → 取默认分类当前有效版本，来源 `DEFAULT_CATEGORY`。
5. 报价日期落在版本边界时取 `[from,to)` 规则；无有效版本返回业务错误而非 0。
6. 建行后修改系统默认、客户默认、产品绑定、版本税率，再调用重算/价格编辑/刷新卡片：行快照和含税金额不变。
7. 删除产品 A 后添加 B：A 行不被改写，B 行按 B 的分类生成新快照；不存在原位 replace API。
8. 13% 和 6% 两行同单重算，各行使用自己的 VAT，不使用报价头覆盖。

### S-BE / S-FE 公式与精度

1. `[增值税]` token 13% → `0.13`；0%、6%、9%、13% 对拍一致；旧普通“税率” token 语义不变。
2. 100 × (1 + 0.13) = 113；113 ÷ 1.13 = 100；前后端精度在容许显示位内一致，禁止 `double` 路径。
3. 无报价行快照时公式返回 `VAT_QUOTE_CONTEXT_REQUIRED / 待报价税率`；日志/响应不得带当前系统税率数值，不得把状态转成 0。
4. 含税元素单价策略在 QUOTE、COST_BASIC、COST_DETAIL 三处读取同一行快照；未税元素价格策略数据库值不变。
5. 缓存/批量计算使用报价行 ID 维度；不同报价同料号不同 VAT 不串值。

### S-UI

1. 逐屏比对税务分类管理、客户默认 VAT、销售产品绑定、客户产品只读、报价创建 Step1、报价 Step2、现有导入抽屉、公式编辑器、BOM 价格策略；1440 与 1280 宽度无重叠/错位。
2. Step2 13% 产品与 6% 服务同屏时，卡片分别显示分类、来源、快照和含税结果；点击重算/刷新后仍相同。
3. 导入抽屉空分类显示默认分类和影响行数；未知编码显示行号并禁用确认；成功导入沿原入口继续。
4. 产品管理无“导入销售产品”按钮；Step2 无“更换产品”按钮，仅保留现有添加/删除。
5. 无报价上下文预览显示“待报价税率”，不显示系统当前 VAT。

## 3. AC 可追溯矩阵

| AC | 可观测断言 | 覆盖分片 |
|---|---|---|
| AC-1 | 13% 产品行显示产品分类来源、13% 快照 | S-API、S-BE、S-UI |
| AC-2 | 6% 产品不被报价头 13% 覆盖 | S-BE、S-UI |
| AC-3 | 标签可插入，13% 返回 0.13 | S-BE、S-FE、S-UI |
| AC-4 | 100→113，113→100 | S-BE、S-FE、S-UI |
| AC-5 | 修改主数据并重算后既有行仍 13% 且金额不变 | S-BE、S-API、S-UI |
| AC-6 | 删除+添加形成新行快照，原行不被替换 | S-BE、S-UI |
| AC-7 | 同报价 13%/6% 行分别展示独立快照 | S-BE、S-UI |
| AC-8 | 产品有效税率优先；缺失时按报价默认再到默认分类 | S-API、S-BE |
| AC-9 | 导入空分类显示默认分类及影响行数并绑定 | S-API、S-UI |
| AC-10 | 未知编码整批拒绝并定位 Excel 行号 | S-API、S-UI |
| AC-11 | 无报价上下文不静默取当前税率，显示待报价状态 | S-BE、S-FE、S-UI |
| AC-12 | 旧税率字段/历史报价可打开且语义不变 | S-BE、S-API、S-UI |

## 4. 回归与证据要求

- 报价创建、Step2 编辑/重算、卡片快照、Excel/PDF/HTML 输出、基础数据导入、客户导入、销售/客户产品列表均需回归。
- 任何失败必须区分本任务引入、既有失败、夹具/环境失败；不能用共享库删除数据“清理”测试。
- 测试报告记录迁移版本、数据库、提交哈希、每个 AC 的输入/操作/断言和证据路径；未经执行不得在本文件写 PASS。
