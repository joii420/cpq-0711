## 7. 规避掉的坑（可沉淀）

1. 定价策略页的左侧客户列表有自己的一组页签，不能用 `.ant-tabs-tabpane-active` 加 `.first()` 定位右侧面板，要按面板名定位。
2. 元素例外列表是「勾选行 + 工具栏编辑/删除」模式，按钮的无障碍名称是 `edit 编辑` / `delete 删除`。删除确认是对话框「确认删除选中的 N 条元素例外？」，里面的按钮是「删 除」。
3. 策略变更历史抽屉：记录是 `tr.ant-table-row`；操作标签是「新建 / 修改 / 删除」；时间只显示到分钟；首次打开时先显示 No data 再加载。**重新打开时会先显示上一次的内容**，等数据行出现不能证明数据已刷新。
4. 开跑前的 `pgrep` 只是某一时刻的采样；同一台机器上其他会话会反复启动 playwright，「等它结束」不能兜底，需要主线协调时段。
