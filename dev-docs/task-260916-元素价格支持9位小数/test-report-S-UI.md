## 6. 过程中规避掉的坑（供复用）

1. 「别的 playwright 在跑」守卫两次失效：①自身 shell 包装进程命令行含匹配串 → 误报；②Node 24 的 `/proc/<pid>/comm` 是 `MainThread` 不是 `node` → **漏报**（证伪实验抓出；改按 `/proc/<pid>/exe` 判断后，假进程能被准确报出）。第一次证伪无效，因为假进程 60s 寿命已过期。
2. 页面上没有「元素管理」字样；审核列表默认只看「待处理」、不显示审核单创建时间（P-6 按目标版本 `V26080505` + 已通过定位，库中唯一）；「查询」不是 `<button>`；矩阵表头日期是 `09-16`。
3. 失败用例 teardown 挂满 timeout（路由未解除），导致 before 第 1 轮 37.9 分钟；已在 afterEach `unrouteAll`。
4. 每条用例各登录一次会被限流 429 → 改会话缓存。
5. `formItem` 的 `has` 子定位不能从抽屉起（会变成「表单项里再找抽屉」）。
