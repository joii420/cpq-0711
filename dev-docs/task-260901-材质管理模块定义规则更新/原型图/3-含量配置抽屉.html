含量配置抽屉 · 只填含量（二级抽屉）

从材质编辑抽屉的配置区工具栏打开，盖在材质抽屉之上；关闭后回到材质抽屉并刷新配置矩阵。这是本次全新的页面。

ⓘ
层级关系：材质管理页 → 材质编辑抽屉（1200 宽，含元素组成区 + 配置矩阵）→ 含量配置抽屉（本页，二级）。
🚨 本页不选元素、不加元素、不删元素（闸门 A 第四轮裁决）—— 元素行按该材质的元素组成预先填好且整列只读，用户唯一能填的是含量列。「有哪些元素」在上一层（编辑态）或新建材质时（原型 6）定。 含量数字一律去掉小数点后多余的 0，输入框里也是 —— 提交时把框里的字符串原样发给后端，75 与 75.000000000000 在 numeric(16,12) 下同值。
