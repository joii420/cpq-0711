配置编号在 100 组时长这样：00198-01 … 00198-99 → 00198-100。 序号用 Java String.format("%02d", seq) 生成（最小宽度 2，超过自然扩位）；不得用 PG 的 lpad(x,2,'0') —— 它会把 '100' 截成 '10'。AC-26

状态 C · 材质存在但一条含量配置都没有空数据

发生于：唯一的配置被停用后（M-2 软删），或导入时该材质的所有配置组都没通过校验。列表只用一个金色 tag 表达，不展开。

注意「元素组成」列有值、而「含量配置」是 0 —— 这不是矛盾。元素组成是材质的显式属性（存在 material_recipe_composition，用户裁决 D10），与有没有配置无关；配置删光了元素组成照样在。
该材质在选配的材质下拉里灰显不可选（见 原型 5 状态 D）。要补配置：选中该行点「编辑」，在抽屉的配置区新建 —— 此时元素组成区还是可改的（见 原型 2 状态 B）。AC-17 · AC-31
