## 🚨 已知坑

1. **antd Select 虚拟滚动** —— 选项一多，`allInnerTexts()` 会漏。要读全须滚动累加。
2. **两字按钮的空格** —— 本项目按钮文案形如「新 建」「创 建」「保 存」，选择器要用 `/^新\s*建$/` 这类正则。
3. **组件管理页是左侧目录卡片列表，不是表格也不是树形条目** —— `.ant-table-tbody tr` 取不到东西。
   每张卡片 = 勾选框 + ▶ 展开箭头 + 目录名 + 统计徽章（`页签6`/`XLS1`/`小计1`）+ 右侧 5 个图标操作；
   组件条目在目录展开之后。真页面见 `证据/真页面-组件管理列表-2026-09-07.png`。
4. **折叠态判据要取状态本身** —— `.svb-grp.collapsed` 的个数，🚫 不要数「可见字段条目数」：
   折叠是 CSS 驱动（`.svb-grp.collapsed .svb-grp-b{display:none}`），**DOM 节点还在，`count()` 数不出来**，
   会得到一个恒绿的假用例（2026-09-07 主线实证）。
