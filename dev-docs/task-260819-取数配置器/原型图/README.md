### 三个设计决定（都不是随手定的，写在这里免得还原时被"优化"掉）

| 决定 | 为什么 |
|---|---|
| 只读页**去掉搜索框**、**页签类型改按钮组而非下拉** | AC-44 的判据是「DOM 中不存在 `<input>` / `<select>`」—— 这是个可机械执行的强断言，值得为它让步。搜索用浏览器 Ctrl+F 顶得住；13 节点 16 边的规模也用不上搜索 |
| 边的编辑用**表单式**，不做拖拽画布 | 画布的实现成本远高于 19 条边的编辑收益，理由与 N-2「不做可视化查询设计器」同源 |
| 四道校验的次序固定为 **③物理存在性 → ①边基数 → ②路径唯一 → ④handler 对账** | 表/列都不存在时，后面三道跑不动也没意义 —— 断言 SQL 本身就写不出来 |
