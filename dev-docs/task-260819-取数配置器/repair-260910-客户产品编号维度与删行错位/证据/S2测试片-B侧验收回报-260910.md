代理给的理由（基于它自己实测到的事实，非推断）：

> 19:53 视图重生成**之前**，8123 上已经跑着含 B-1~B-5 全部 Java 改动的代码，产品页签仍是 **4/7/4 行**，与 master 逐字节相同（证据 `05`/`06`）；重生成之后同样的代码、同样的库变成 1 行。
> ⇒ **决定行为的是已落库的 `sql_template`，不是编译器的实时产出。**
> 回滚 `SemanticCompiler` 而不重新编译视图，渲染必然不变，实验必然「不变红」——按 §3④ 的字面判据会被读成「白测」，那是错误结论（`testing.md §5.5` 形态②「验了一个恒真的东西」）。

而真正意义上的回滚 = 把共享库的 `sql_template` 改回旧版 = **全局配置写入**，不在 S2 写入面内，代理**无批准权，未执行**（纪律正确）。
