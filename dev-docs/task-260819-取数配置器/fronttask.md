## 2. 三条容易踩的坑

1. ⚠️ **探本机服务必须加 `--noproxy '*'`** —— 本机 `http_proxy=127.0.0.1:7890` 会让 `localhost` 走代理返 502，看起来像服务挂了
2. ⚠️ **worktree 里没有独立的 dev server**：5174 是主仓的。worktree 自检要软链 `node_modules` + 另起临时端口，或用 `tsc` 查真实文件
3. ⚠️ **antd 选择器坑**（`cpq-playwright-selector-pitfalls`）：类名不稳、两字按钮渲染成「保 存」、下拉虚拟滚动 —— 这四个坑都表现为 timeout，容易误判成产品 bug
