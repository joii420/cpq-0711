## 🚨 量具换过两次，前两次都是失效的 —— 这一段必须留着

| 版本 | 量具 | 结果 |
|---|---|---|
| v1 | `getByRole('tab')` + `.ant-table-tbody tr.ant-table-row` | **全返 -1**，而 Playwright 报 **`1 passed`** |
| v2 | 同上，改走详情页 | **仍全返 -1**，仍报 `1 passed` |
| **v3** | **页面渲染文本**（`document.body.innerText`） | ✅ 8/8 卡片取到真实行数 |

**根因**：本页的页签与表格**都不是 antd 原生类名**（自定义渲染）⇒ `.ant-tabs-tab` / `.ant-table` 恒 0。
🔑 **恒 0 被 `count()` 返回后当成了「就是 0 行」**，而不是「没找到元素」——
判据落在一个「无论功能好坏都给同一答案」的维度上，**本任务第 6 次同族**。

⇒ v3 加了**量具自证**（不满足就硬失败，不许据此下结论）：
```
expect(text.length).toBeGreaterThan(500)        // 文本非空
expect(text).toContain('产品小计')                // 页面真的渲染了卡片
expect(cards.length).toBeGreaterThan(0)          // 真的切出了卡片
```
