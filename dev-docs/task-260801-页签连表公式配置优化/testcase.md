### 3.1 分栏 / 宽度自适应（AC-1 / AC-2 / AC-18）

#### TC-01（覆盖 AC-1）左右分栏 42:58 + 两栏独立滚动
- **前置**：登录 admin，进入组件管理页，选中「罗克韦尔/产品」组件，打开一条已有公式的「配置」抽屉。视口 1920×1080。
- **步骤**：
  1. F12 量抽屉整体宽度，应为 `1520px`（`min(1520px, 92vw)`，1920 视口下 92vw=1766.4 > 1520，取 1520）。
  2. 量左右两栏容器宽度比例，应接近 `42% : 58%`（对应 `grid-template-columns: minmax(430px,42fr) minmax(520px,58fr)`）。
  3. 把左栏内容滚到底（若内容不足一屏可临时收窄浏览器窗口触发滚动条），观察右栏公式框/工具条位置是否随之滚动。
  4. 反向：滚右栏，观察左栏是否不动。
- **预期**：抽屉宽 1520px；左:右 ≈ 42:58；左右两栏各自有独立 `overflow:auto`，滚一栏不影响另一栏；两栏之间有 1px 分隔线。
- **判定方式**：目测 + DevTools 量尺寸
- **当前可执行性**：待前端交付后执行

### 3.1b 行键可比性判定（AC-4，基础态·非搜索）

> 补齐点（技术总监裁决 2026-08-01）：AC-4 原正文只在搜索态（TC-31）里顺带验证了"置灰语义不受搜索影响"，缺一条独立、不搜索、直接打开抽屉就验证置灰+可点的基础用例。裁决结论：**在用例集里补，不新增 AC 编号**（置灰是本次改动风险点必须测；"可比 chip 可点插入"是既有行为的回归项，拆分 `TabFieldMatrix` 有可能改坏它，同样必须测）。

#### TC-04b（覆盖 AC-4）非搜索态：不可比页签明细 chip 置灰 + hover Tooltip 原文
- **前置**：组件管理页选中「核价模板/产能」（COMP-0050，`rowKeyFields=["销售料号","工序编号"]`），打开公式配置抽屉，**不输入任何搜索词**。
- **步骤**：
  1. 在左栏找到「物料BOM」卡片（COMP-0048，`rowKeyFields=["销售料号","组成料号"]`，与宿主行键不同）。
  2. 观察该卡片的明细字段 chip 视觉样式（应为置灰，如 `#f5f5f5` 背景/浅色文字，区别于正常 chip）。
  3. 尝试点击其中一个明细 chip。
  4. 鼠标 hover 该 chip 3 秒以上，等待 Tooltip 弹出，记录文案。
  5. 换「物料与元素BOM」卡片（COMP-0049，`rowKeyFields=["销售料号","材质料号","元素代码"]`）重复步骤 2-4。

- **判定方式**：目测
- **当前可执行性**：待前端交付后执行

- **前置**：技术总监补充要求（2026-08-01）：需给出可判定的量化观察方法，而不仅是"目测容器高度封顶"。
