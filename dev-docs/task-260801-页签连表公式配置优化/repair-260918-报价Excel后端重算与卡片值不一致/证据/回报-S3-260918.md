## 规避的坑（含本次暴露的）

1. **`pgrep -f "node.*[p]laywright test"` 会命中 shell**：命令行文本里含这段模式的 bash 进程也会被匹配，包括我自己的命令，以及别的会话的等待循环（本次 1131012 就是）。改用 `ps -C node -o pid=,args= | grep "playwright test"` 只看 node 进程，命中时再用 `/proc/<pid>/cwd` 核实身份。
2. **编辑页不能用 `networkidle`**：页面有持续请求，而这个等待没有超时，会一直挂着。已改为 `domcontentloaded` 加等待具体元素。
3. **Playwright 配置里 `testDir` 按配置文件所在目录解析**：配置放在 `e2e/` 下时要写 `'.'`。
4. **表头带 `[col_key]` 前缀**：要去掉前缀再比较，否则 toContain 会误报红。
5. **`finally` 里不能用 `page.waitForTimeout`**：页面因超时关闭后它会抛错，操作后的 SELECT 就被跳过，证据缺一半。已改为 Node 级 `setTimeout`，登录框也加了 30s 显式等待。这两处加固**只动了测试的收尾和等待逻辑，没动任何 AC 断言**；加固后正式轮 r3 与证伪轮 r2 都已重跑。
6. `quotation_line_item` 没有 `updated_at` 列，参考信息改取单头的字段。
