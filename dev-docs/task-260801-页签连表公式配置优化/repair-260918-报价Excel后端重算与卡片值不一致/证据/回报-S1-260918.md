## 7. 规避的坑

- curl 一律加 `--noproxy '*'`；检索一律用 `/usr/bin/grep -a`。
- 探活时核对身份：每次运行先比对 `totalElements` 与 `cpq_db_0724.quotation count`，对不上就退出码 2。
- 修掉了原脚本 `dec()` 把 null 当 0 的假绿；另外 E-5 推广项第一版漏算了判定值缺席的格（29 → 37），已修正并复跑。

- 证据目录每次新建，加后缀防覆盖，本轮已有 6 个目录，都没有被覆盖；cookie 文件在运行结束时删除。
- T1.4 的 columns 从库里的 `component.excel_columns` 取，不取被测后端的响应，避免判据和被测对象同源。
- **T1.6 / T1.8 的 diff 口径偏离 AC 原文，请主线确认**：AC-10 / AC-13 原文写的是 `git diff master...HEAD`，但子代理不提交代码。21:51 采样 `git status`，worktree 里 `ExcelViewService.java`、`CardEffectiveRows.java` 都是**未提交的修改（M）**。三点 diff 只比较已提交的内容，此时会得到空结果，读起来就像「无迁移、前端零改动、核价侧无改动」，是假绿。脚本已改为比较 `merge-base` 与**工作区**（包含未提交改动），并加 `status --porcelain --untracked-files=all`，用来发现未跟踪的新迁移或新前端文件。如果主线会在 S1 正式执行前先提交，两种口径的结果相同。
