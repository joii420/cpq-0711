## 3. 各片要点

### S1（只读）

- **只对固定单据清单断言**（`证据/输出/固定单据清单-260918.tsv`，31 张单，按 `quotation_id`）；运行期间别人新建的单（含 S2 的复制单）一律不计入。🚫 不许写「共 N 格」这类全局计数断言 —— 按清单逐格断言，格数只打印。
- 断言前先断言非空：每行 `quote_card_values` 非空；T1.2 须覆盖三个 Excel 组件各至少 1 格。
- A/B（T1.1、T1.3、T1.4、T1.5）两次请求须在同一分钟内发出。
- T1.7：先算 md5 → 执行 T1.1~T1.5 → 再算 md5；不同则逐行定位变化行，写明是否与本片请求有关。
- T1.6：`mvnw test` 只跑点名的三个类（`-Dtest=GetExcelViewCostingIT,CostingExcelTreeTabKeyIT,EffectiveRowsKeyContractTest`），🚫 不跑全量（`mat_*` 表从未创建，全量永远不绿）。master 基线取后端工程师 B-7① 回报里的同三类结果。

### S2（私有写）

- **造数**：只用 `POST /api/cpq/quotations/{源单id}/copy` 复制出的单。源单：0881（`40fe7ae7-c6e1-403a-aa30-17989ec758e9`）得 C1、C3、C4、C5；`QT-20260907-0564`（`a99bfc8d-2bd1-432a-af67-436c7160a09c`）得 C2。
- **标记**：每张复制单创建后**立即**把 id 写进本片回报文件，并把单名改为 `RP0918-S2-<原名>`（SQL：`UPDATE quotation SET name = 'RP0918-S2-' || name WHERE id = '<本片单 id>'`，执行前先 `SELECT count(*)` 确认恰好 1 行）。
- **置值纪律**：对正式账 / 存值的每一次 `UPDATE` 都必须 `WHERE id = '<本片复制单的行 id>'`，执行前先 `SELECT count(*)` 确认恰好 1 行。🚫 不许对源单或任何非本片单写入。
- **收尾**：`finally` 里 `DELETE /api/cpq/quotations/{id}` 删除全部本片复制单，并用 `SELECT count(*) FROM quotation WHERE id IN (…)` 确认为 0；删除失败的单列入「待清理清单」写进回报，🚫 不许改用 SQL 批量删除。
- 同一状态下本分支（8328）与 master（8081）各请求一次；AC-12 的写动作分开用 C4（本分支）与 C5（master），不共用一张单。
- T2.2 用 `openpyxl` 读数值单元格原值（不是显示格式）与判定值比较，容差 `1e-9`。
