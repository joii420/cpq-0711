## 1. 任务拆分

### T1（RED）· 单元测试先行 —— `buildEditRowsFromRowData` 的行为契约

新建 `cpq-backend/src/test/java/com/cpq/quotation/service/EditRowsFromRowDataTest.java`（纯单测，不连库）：

| 用例 | 断言 |
|---|---|
| `T1.1` 无墓碑、等长 | 每个 baseRow 得到一条 editRow，`rowKey` 与 `uniquifyRowKeys(buildRawRowKeys(...))` 逐字相等；`values` 只含 INPUT* 键 |
| `T1.2` 只回种 INPUT* | `row_data` 里的 FORMULA / BASIC_DATA / DATA_SOURCE / FIXED_VALUE 键**不得**出现在 `values` 里 |
| `T1.3` 键存在即已定值 | `""`（显式清空）必须被回种（不是当成"没填"跳过）；键缺失则不回种 |
| `T1.4` 墓碑对齐 | 6 行 baseRows + 2 条墓碑 + 4 行 row_data → 回种落在**保留的 4 行**上，不发生错位（错位会写到别的料号头上） |
| `T1.5` 尾部手动行 | row_data 比保留行多出的尾部行被忽略，不抛异常 |
| `T1.6` 校验失败即跳过 | 人为把某行 row_data 的行键字段值改掉（模拟错位）→ 该行**不回种**（返回值里没有它），其余行照常 |
| `T1.7` 价格锁豁免 | `driverRow.__priceLocked=true` 的行不回种任何键 |
| `T1.8` 空/缺失输入 | `row_data` 为 null / 空数组 / 组件无 rkf → 返回空映射，不抛 |

### T2（GREEN）· 实现 `buildEditRowsFromRowData` 并接进 `buildCardValues`

**新增私有方法**（`CardSnapshotService`）：

```java
/** 从 quotation_line_component_data.row_data 回种用户已定值的 INPUT* 列 → editRowsByComp。 */
private Map<String, ArrayNode> buildEditRowsFromRowData(
        JsonNode snapshot,                       // 冻结结构 tabs（提供 fields / componentId）
        Map<String, ArrayNode> baseRowsByComp,   // 已按 prunedNodeIds 过滤后的 baseRows
        Map<String, String> rowDataByCompId,     // 新增：component_id → row_data JSON
        Map<String, JsonNode> rkfByComp,
        Map<String, List<DeletedRowKeys.Tombstone>> delByComp)
```

算法（每组件）：
1. `rawKeys = formulaCalculator.buildRawRowKeys(rkf, fieldsDef, baseRows, deleted)`；`uniqKeys = uniquifyRowKeys(rawKeys)` —— **复用 E1 的唯一入口**
2. `keep = DeletedRowKeys.keepMask(uniqKeys, fps, nodeIds, deleted)`（与 `computeRows` 同款；`deleted` 空则全保留）
3. 顺序配对：第 k 个 `keep` 行 ↔ `row_data[k]`
4. **校验**：用行键字段名从扁平行直读，拼出内容键，与该 baseRow 的 `computeRowKey`（不带 nodeId 前缀）比对；不等 → **跳过该行**并计数
5. **价格锁**：`baseRow.driverRow.__priceLocked == true` → 跳过该行
6. 取值：遍历 `fieldsDef`，`fieldType ∈ {INPUT, INPUT_TEXT, INPUT_NUMBER}` **且** `editable != false` **且** 扁平行里该键存在 → 写进 `values`
7. 产出 `{rowKey: uniqKeys[i], values:{...}}`；`values` 空则不产出该行
8. 跳过行数 > 0 → `LOG.warnf` 打出 `line/comp/skipped/total`（**不静默**）

**接线**（3 处小改）：
- `buildCardValues` 的 compData 查询（`:1264-1268`）补选 `row_data` 列 → `rowDataByCompId`
- `CardValuesPrefetch.compDataByLine` 的整单预取 SQL 同步补列（不改则 prefetch 路径拿不到 → 两条路径行为分叉，AP-41 族）
- `:1298` 的 `null` 实参换成 `buildEditRowsFromRowData(...)` 的返回值

## 2. 雷区清单（写代码时逐条对照）

| # | 雷 | 纪律 |
|---|---|---|
| R1 | 用 `row_index` 当 baseRows 下标 | **禁**。baseRows 已被 `prunedNodeIds` 过滤过，`row_data` 又是"减墓碑"口径，两次过滤不同源 —— 必须按 §1-T2 的 keep 序配对 + 内容校验 |
