## 3. 测试用例大纲

### TC-1 / TC-4 主链路（一条连续会话跑完，中间态与终态都要断言）

```
① 记录 7 表 count(*) 基线
② 新建单 Q1 → 导入 Excel → 断言（AC-1）：
   material_bom 该组 = 1 行 / is_current=t / pending_quotation_id IS NULL / bom_version='2000'
   记录该行 id 为 :id1
③ 新建单 Q2 → 导入同一 Excel → 断言（AC-4）：
   7 表 count(*) 与 ① 逐表相等（差值全 0）
   material_bom 该组仍 1 行、bom_version 仍 '2000'、id 仍 = :id1   ← 证明未删旧行重写
```

⚠️ **`id` 逐字相同这条断言不能省**：只比 `count(*)` 和版本号，无法区分「没写」与「删了再写一模一样的一份」。这正是 `RECORD.md` 2026-08-29 沉淀的「在 X 实际发生的那一层取证」。

### TC-5 反向期望（防止修成「永不升版」）

改 Excel 中 `202601010001` 净重 +1 → 新建 Q3 导入 → 断言新增 `2001` 行且 `is_current=false`、`pending_quotation_id=Q3`，原 `2000` 行不受影响。

### TC-6 / TC-7 核价回填两条路径

- TC-6：Q1 不改值 → 提交 → 核价通过 → 断言走 NOOP（该组不进 `backfill.versionedGroups`），行 id 仍 `:id1`
- TC-7：另起 Q4 走完 AC-1 → 在页签改一个数值为 V → 提交 → 核价通过 → 断言新增 `2001` 且 `is_current=true`、原 `2000` 翻 `false`、新行该列 = V

### TC-14 ~ TC-18 版本号内容寻址（一条连续会话跑完）

```
① AC-1 已完成，该组存在正式行 2000
② 改 Excel 净重 +1 得 F2
③ 新建 Q3 导 F2 → 断言 bom_version='2001'
④ 新建 Q4 导 F2 → 断言 bom_version 仍='2001'（不是 2002）   ← TC-14 核心
⑤ 新建 Q5 导 F2 → 断言 bom_version 仍='2001'
⑥ 断言该组 2001 共 3 行，pending 分别 Q3/Q4/Q5，is_current 全 false，2000 行不受影响
⑦ Q3 核价通过 → 断言其 2001 转正；Q4/Q5 的 2001 仍在        ← TC-16 上半
⑧ Q4 核价通过 → 断言 Q4 的 2001 被删除、无 uq 异常、终态 is_current=true 恰好 1 行  ← TC-16 下半
⑨ 净重再 +1 得 F3，新建 Q6 导入 → 断言得 2002                ← TC-17
⑩ 导 A→导 B→再导 A → 断言第三次得 2003 而非复用 2001         ← TC-18（钉死已知代价）
```

⚠️ **第 ⑧ 步是本次扩范围新增的最高风险点**：若 B-14 未落地或判定写错，此处会抛 uq 冲突异常。**必须真跑两单先后核价，不许只测单张单**。

### TC-19 迁移前置冲突检测

在执行 S-5 迁移**前**，对 5 张表各跑一次按新键的 `GROUP BY ... HAVING count(*)>1`，断言全部返回 0 行。
🚨 非 0 行 → **停下报主线**，不许自行删除或合并（§3.2）。

## 4. 🔬 还原实验（强制，不做则本轮测试结果不予采信）

**全绿之后必须做两组**：

**第一组（首次落地）**：把 B-2~B-5 的新增条件改回原样（即恢复 `if (spec.pendingQuotationId != null)`），重跑 TC-1 与 TC-4。

**第二组（版本号内容寻址）**：把 B-13 的复用逻辑改回 `MAX+1`，重跑 TC-14。**预期变红**（版本号回到 2001/2002/2003 递增）。

- **第一组预期**：TC-1 变红（落 pending 行而非正式行）、TC-4 变红（7 表出现非零增长、版本号涨到 2001）

## 5. 假绿防范清单（本仓历史踩过的坑）

| 风险 | 防范动作 |
|---|---|
| **测了旧代码** | 确认 dev server 已重载（改 java 后看 Quarkus 热重载日志）；worktree 里跑测试须 `cd <worktree>/cpq-backend`，在主仓跑会测错树 |
| **`grep` 静默返空** | 本环境 `grep` = `ugrep -I`，中文注释多的大源文件会被判为二进制返空。下「无引用」结论必须用 `/usr/bin/grep -a` 复核 |
| **调用层日志当正确性证据** | 「没写行」要查真实行数 / 真实 SQL（`org.hibernate.SQL=DEBUG`），不能停在返回值与耗时上 |
| **共享库数据漂移** | 多 worktree 共享 dev 库，判定「回归」前先在干净 master 上做同型 A/B 对照，别把既有失败误归因给本次改动 |
| **N+1 混进批量路径** | B-3 / B-5 必须给出 statement 计数证据：SQL 条数与组数 N 无关 |
