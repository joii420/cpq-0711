另外，我对库里的 `col_1`/`col_3` 是**先舍到 9 位再比较**的，依据是 ⑥「数值断言一律按 9 位小数比较」。如果主线要求按库里原文逐字比较，需要告诉我。

## 4. 过程中踩到并已规避的坑

1. **编辑请求是 PUT。** 等待条件最初按 POST 过滤，导致 E-2 等 60 秒超时；改为不按请求方法过滤。
2. **存草稿请求体的结构**是 `added/modified`，不是 `lineItems`；最初因此解析出 0 条（假红），已改为三种都收。
3. **截图拍不到公式列**：公式列在横向滚动区右侧，第 4 次运行的 E-0 / E-1 / E-2 截图 md5 完全相同，属于恒真证据。现在截图前先把可横向滚动的容器滚到最右，并只截产品卡片。
