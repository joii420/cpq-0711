── 2. D-19 与 B-15 必须【同批】报出，不是改一轮传一轮 ──────────────────
自造组合负例：第2行 CUST-0004（合法）/ 第3行 CUST-0001（真实客户但不是本次）/ 第4行 8000142（不存在）
  status = FAILED   message = 导入校验未通过，共 3 处问题，本次未写入任何数据
    第4行 [客户编号] 客户编号未在客户档案中登记                        ← D-19，排在前
    第3行 [客户编号] 本次导入客户为 CUST-0004，…：CUST-0001（第 3 行）  ← B-15
    第4行 [客户编号] 本次导入客户为 CUST-0004，…：8000142（第 4 行）    ← B-15
  📌 第4行同时命中两条、各报一条，是刻意的：两条说的是不同的事
     （「这个编号不存在」vs「这个编号不是本次客户」），合并会让用户不知道该改哪。

── 3. 不误伤 ─────────────────────────────────────────────────────────

  ⇒ B-15 新增的逐行循环是纯内存，对最大规模文件无可测影响。

── 5. ⚠️「返 400」的实际可观测形态（据实记录，未含糊）──────────────────
