🚫 **不采信代理的「已完成」**，也不把「测试全绿」当 AC 达成的证据 ——

⚠️ 三条已知会被误读为缺陷的，先记下免得当场误判：
1. `missing table [mat_composite_process]` 启动 ERROR —— **预先存在**，与本段无关

## 4 · 亲验之后

```
亲验通过 → 落 B-3（26 ALTER）+ D-35 建表 → 合并 master → 广播并发会话
         → 补验 AC-1⑤ / AC-8 → 闸门 B 交用户验收
```
🔑 落库与推 master 必须同批：先合并会让所有人报「缺列」，先落库会让 master 代码报「多列」。
真正的风险不是秒数，是**广播覆盖率** —— 尾巴拖到最后一个会话合并为止。
