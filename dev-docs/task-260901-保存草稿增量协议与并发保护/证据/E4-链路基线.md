## 一个大请求会拖垮同时段所有请求

4 个 24.6 MB 的 `getById` 并发期间：

| 指标 | 空闲 | 拥塞时 |
|---|---|---|
| 0 行空单 `getById` | 0.18 s | **7.6 / 9.2 / 9.8 s** |
| 20 次空 SQL 往返 | 0.43 s | **26.0 s** |
| `ping` | 32 ms | **878 ms**（缓冲区膨胀） |

⇒ **验收时必须确保无其他大请求在跑**，否则同码同数据可测出 16 s 与 43 s 两种结果（`repair-260829` 已记录同类矛盾）。
