# 前端任务分解

## 原型实现约束

原型图以当前系统实际页面为基准：沿用 `MainLayout`、现有页面的 Card / Tabs / Table / SelectableTable / Drawer / Steps / Segmented 组件层级、间距和状态表现。原型确认后按对应 HTML 原型 1:1 实现，不新增概念化页面壳，也不把现有 Drawer 改成独立新页面。

## F-1 币种管理页面（服务 AC-1、AC-2、AC-18、AC-23）

新增币种列表、顶部工具栏新增/编辑/启停/删除动作；汇率列显示 `1 USD = 7.200000000000 CNY`，CNY 行不可删除和停用。

## F-2 汇率历史与导入（服务 AC-1、AC-2、AC-11、AC-20、AC-24、AC-25）

在币种列表行提供“历史汇率”入口，右侧 Drawer 展示当前币种按日期的全部汇率历史、来源和更新时间；同一天多次更新时标记最后一条为当天有效值。Drawer 和列表提供“导入汇率”入口，不提供刷新汇率按钮。

## F-3 客户默认币种和元素价格导入（服务 AC-3、AC-5~7、AC-21）

客户表单增加默认币种选择；元素价格导入抽屉把币种提升为整批必选项，结果表同时展示源价格和 CNY 基准价，旧模板冲突时显示逐行失败明细。

## F-4 报价单单头币种快照（服务 AC-4、AC-9~11、AC-15~16）

报价单创建时展示并保存币种、汇率、汇率日期、来源和命中策略；报价单保存后全部只读，不提供币种切换和汇率刷新入口。

## F-4a 汇率策略与试算（服务 AC-10、AC-14、AC-23）

在定价策略客户列表中增加“汇率策略”Tab。每个客户配置一套适用于全部目标币种的取值方式：最新一条、平均/最高/最低窗口方式，以及指定日期、上月某天、每月（指定日）、上月最后一天日期方式；不配置价格源、系数或加价。最新一条右侧不显示窗口参数，提示取目标日期当天最后更新的一条；页面显示名称为“每月”，右侧参数为 1~31 日输入框；平均/最高/最低显示窗口数和单位，指定日期显示日期控件且最大值为今日，上月最后一天不显示可编辑参数。日期参数按报价单创建日解析，短月跳过，命中日期无汇率时显示错误。提供策略试算 Drawer，展示解析后的目标日期、当天最后有效汇率和最终结果。

## F-5 产品卡片与核价双币种小计（服务 AC-8、AC-12、AC-16~17、AC-22）

报价侧保留现有元素、金额、页签小计、产品小计等列名，不在列名中追加币种；汇率换算体现在小计数值上，报价侧显示报价币种金额（例如 `15,000.000000000 JPY`），不使用人民币 `￥` 符号。报价侧元素单价、公式金额和产品小计仅显示报价单币种，不增加 CNY 小计行；元素单价最多展示 9 位，汇率显示 12 位。仅核价侧产品卡片同时展示 CNY 小计和外币小计，核价人民币公式值不变。组件公式编辑器增加 `[汇率]` 标签，只有用户显式引用时才参与计算；对应原型为 `原型图/组件公式汇率标签.html`，双币种展示对照 `原型图/双币种小计与比对.html`（报价侧）和 `原型图/核价双币种小计.html`（核价侧），不得把双币种展示应用到报价侧。

## F-6 比对视图外币比较（服务 AC-13、AC-17）

比对视图显示报价单币种和汇率上下文，报价侧与核价侧均以外币小计展示差异；CNY 基础值作为辅助信息展示，不参与外币列的误差计算。

## F-7 前端契约、精度和回归（服务 AC-1~27）

更新类型、service、权限入口和已有报价/核价/比对页面回归；执行 `tsc -b`、构建和原型逐屏比对。

## F-8 汇率历史导入（服务 AC-24、AC-25）

实现单目标币种 Excel 导入 Drawer、模板下载、整批预校验、逐行预览和错误回显；导入成功后刷新历史列表。同一生效日期允许新增历史更新，列表以更新时间标记当天最后有效记录；无效汇率和格式错误不得产生半批数据。
