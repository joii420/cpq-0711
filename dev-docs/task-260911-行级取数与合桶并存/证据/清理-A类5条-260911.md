## 五、教训

**「说不出数字就不许执行」这一步是唯一拦住误删的东西。**
判据是后端和主线**共同**推出来的，两人都认为它成立；用户也据此批准了。
真正拦下来的不是谁更谨慎，而是**执行前必须先把命中面数出来**这条硬规则 ——
数出来之后，"5 / 7 / 24 / 1" 这个分布自己就把判据否掉了。

📌 与 `subagents.md §5.5` 呼应：**批准的有效性取决于批准时他掌握的信息**。
信息变了（出现了他批准时不知道的分布）就要**重新问**，而不是"他批过了所以我可以执行"。
