## 关键测试

1. **迁移**：空测试库跑 Flyway，断言七单位、18 条同类型有向关系、无跨类型/自关系；重复启动不重复插入。
2. **方向**：分别验证 `2000 PCS → 2 KPCS` 与 `2 KPCS → 2000 PCS`；修改一个方向不影响另一个方向。
3. **大小写**：`pcs`、`PCS`、`Pcs` 均匹配同一单位；创建 `pcs` 与既有 `PCS` 冲突返回 400/409 契约值。
4. **无结算单位**：来源存在但客户产品结算单位为空，页面/公式/小计/导出均保持原值。
5. **跨类型**：`kg → PCS` 与 `PCS → kg` 均保持原值，且数据库不存在此类关系。
6. **异常透传**：未知（含汉字单位）、缺关系、停用均不返回 500；原值不变并有诊断证据。
7. **冻结序列**：草稿算 2 → 提交 → 后台系数改为 0.002 → 已提交普通打开/刷新/重算仍为 2 → 新草稿重算为 4。
8. **权限**：真实管理员会话写入成功；销售代表、销售经理、定价经理页面不可达且写接口 403。
9. **并发**：两个版本相同的编辑请求先后提交，第二个 409 且第一份结果未被覆盖。
10. **N+1**：构造多报价行、多单位，断言单位/关系与结算单位查询次数不随行数线性增长。
11. **协议回归**：组件字段保存值仍为 `unit_source_field: "unit_code"`，相关报价 E2E 无“加载中”残留。
12. **前端自检**：`npx tsc -b`；每个改动 TSX 的 Vite URL 200；`/system/units` 与 `/products-hub` 200；相关 Playwright 全绿并留截图。
13. **核价导入**：两套物料页分别导入 `pricing_unit=kg` 与 `pricing_unit=g`，断言两张表各自保存且互不影响；旧模板缺列仍成功导入。
14. **核价目标**：销售料号绑定根生产料号 `P-001`，基础核价以基础表计价单位换算，详细核价以详细表计价单位换算；子件目标不变；无绑定/无计价单位原值透传。
15. **核价冻结**：提交后修改计价单位和单位关系，已提交核价单普通打开、刷新、重算、版本切换和导出均保持提交时结果；新草稿读取最新值。
