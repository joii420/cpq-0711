## 页面协议

- 列表操作只放顶部工具栏，选择不足时按钮不隐藏，显示禁用和 Tooltip。
- 所有编辑使用右侧 Drawer；不使用 Modal 表单。
- 单位匹配请求和本地兜底均按大小写不敏感规范化；展示使用后端标准代码。
- 关系 Drawer 的每行标签为“1 {来源单位} = [系数] {目标单位}”，避免方向歧义。
