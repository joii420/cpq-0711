## 数据约束

- 单位代码使用规范化值建立大小写不敏感唯一约束，API 返回保存的标准显示代码。
- 关系唯一键为 `(source_unit_id, target_unit_id)`；来源与目标不得相同、必须同类型、系数必须大于 0。
- 正向与反向关系独立存储，服务端不自动按倒数改写。
- 报价批次一次性取齐所需关系；禁止在单元格/行循环内查库。
- 核价批次一次性取齐客户、销售料号→生产料号绑定，以及基础/详细各自的计价单位；禁止在核价行或子件循环内查库。
- 基础核价只读 `ds_cost_basic_material.pricing_unit`，详细核价只读 `ds_cost_detail_material.pricing_unit`，不使用另一套表补空。
