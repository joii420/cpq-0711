## §4 用例设计要点（防四类假绿）

| 风险 | 本任务的具体形态 | 防法 |
|---|---|---|
| **空验证** | AC-10/11/12 修复前本就是 0 行；若用例写成「断言 ≥0 行」永远绿 | 断言**具体行数与具体值集合**；并做**还原实验**：把 B-5 改回带桥，用例必须变红 |
| **测了旧代码** | 共享 dev server + 热重载，可能仍跑改动前的 class | 每轮测试前记录后端启动时间戳；AC-13 直接查库里的 `sql_template`（改没改一眼看出） |
| **测错树** | `mvnw` 在 `cpq-backend/`，子代理容易 cd 到主仓跑 | 单测必须在 **worktree 的 `cpq-backend`** 里跑，回报附 `pwd` |
| **串扰假红** | S1 与 S-全局 并行会让 S1 读到被改的生效配置 | S-全局 **串行殿后**（本文件 §3） |
| **选择器坑** | antd 类名 / 两字按钮「保 存」/ 下拉虚拟滚动 | 参照 `cpq-playwright-selector-pitfalls` 既有经验；timeout **先怀疑选择器**再怀疑产品 |
