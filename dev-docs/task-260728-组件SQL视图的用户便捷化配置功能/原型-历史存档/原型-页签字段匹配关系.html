核心模型：用户只选「页签类型」一项；可用字段面板按导入 Sheet 分组展示该页签能取的所有字段。 主数据源、判别式、取数锚点、行身份料号全部由页签类型推导，用户不接触表名与 JOIN。
行身份料号是关键概念——它既是「这一行代表谁」的标识，也是所有附属源的关联键。
