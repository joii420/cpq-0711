## 5. 代理规避掉的坑（6 条，原文要点）

1. 🚨 **差点把右侧三个按钮挤出可视区（直接命中 AC-20）**。`SelectableTable.tsx:187-200` 的 toolbar 是 `display:flex; justify-content:space-between; flexWrap:wrap`，原来只有 2 个 flex 子元素。若把 3 个新控件平铺成兄弟节点，flex 子元素变 5 个，`space-between` 会均匀摊开，窄屏时按钮组被推到第二行甚至挤出。修法：左侧 4 个条件控件整体包进 `<Space wrap>`，恢复两个 flex 子元素结构。
2. ⚠️ **差点用错自检命令**。派工写的是 `npx tsc --noEmit`，但 `docs/rules/frontend.md §2.1` 有更正：根 `tsconfig.json` 是 solution-style（`"files": []`），`tsc -p`（不带 `-b`）**编译 0 个文件、恒返回 0** = 空验证。改用 `npx tsc -b` 并做了证伪实验。
3. ⚠️ **空串条件差点被当成有效过滤发出去**。`partNo` 初始 `''`，直接传会把 `partNo=` 塞进 query，后端可能解读成搜空料号 → 全表 `LIKE '%%'`。已统一 `partNo || undefined`。
4. ⚠️ **`templateService.list` 返回形状不统一**。`TemplateList.tsx:96` 直接 `res.data`（数组），`ProductTemplateBinding.tsx:194` 写 `Array.isArray(tdata) ? tdata : (tdata?.content || [])`。已按后者做双形状兼容。
5. ⚠️ 字典拉取失败各自 `try/catch` + `message.error`，不中断列表加载（否则污染 AC-5 的「无未捕获异常」）。
6. ✅ 切页签不清空料号（AC-7）：`partNo` 是独立 state，Tabs 的 onChange 只动 `statusFilter` + `setPage(0)`。
