## 2. 生产料号从哪来（代码）

- `ProductionPartInfoService.loadByMaterialNos`：`ds_quote_material (customer_no, material_no) → production_no`，
  注释「🚨 customer 过滤不可省，同一销售料号在不同客户下各存一行，漏过滤即跨客户串号」；
  「旧链路（已废弃，勿复活）：`internal_material` → 兜底 `material_master`」。
- `QuotationService.loadLineItems`（约 `:3629` / `:3692`）：卡片「销售料号」徽标的生产料号浮层用上面这条链路，
  客户取 `quotation.customer_id → customer.code`，销售料号取 `resolveHfPartNo(li)`（快照为空才回退 `product.part_no`）。
- 现有料号搜索（`QuotationService.list`，`partNo` 分支）：只比对 `li.productPartNoSnapshot` 与 `li.customerPartNo`。
