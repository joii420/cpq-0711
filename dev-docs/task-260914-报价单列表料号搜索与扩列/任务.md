## ① 背景与目标

### 用户原话（归档，勿改写）

> 报价单管理- 功能增加:
> 1.增加料号搜索: 输入料号可以过滤报价单中存在该料号的单据
> 2.报价单列表增加列:
>  - 产品分类: 报价单的产品分类

### 5.2 性能

- 料号过滤走 `EXISTS (SELECT 1 FROM quotation_line_item ...)` 子查询。当前行项 5277 行，`LIKE '%x%'` 全扫可接受。
- ⚠️ **本期不加索引**：`LIKE '%x%'` 用不上 B-tree 索引，要真提速得上 `pg_trgm` GIN 索引 = DDL 迁移 = 回标准档。行项到**十万级**再评估，登记为观察项。

## ⑥ 任务分解

> 接口变更集中在本节（轻量档不单出 `api.md`）。

### 接口契约变更（加法式，对既有调用方零影响）

`GET /api/cpq/quotations` **新增三个可选查询参数**：

| 参数 | 类型 | 语义 |
|---|---|---|
| `partNo` | string | 料号模糊搜索。对 `quotation_line_item.product_part_no_snapshot` **或** `customer_part_no` 做不区分大小写的包含匹配；命中任一即命中该单 |
| `categoryId` | string | 产品分类过滤。传 UUID = 该分类；传字面量 **`NONE`** = 未分类（`product_category_id IS NULL`）；不传 = 不过滤 |
| `templateId` | UUID | 报价模板过滤（对 `customer_template_id`）；不传 = 不过滤 |

`QuotationDTO` **新增两个只读字段**（只增不改，既有字段一个不动）：

| 字段 | 语义 |
|---|---|
| `categoryName` | `product_category.name`；`categoryId` 为空或查不到 → `null` |
| `templateName` | `template.name`（不含 version）；`customerTemplateId` 为空或查不到 → `null` |

> 🚫 这两个字段**只在列表查询里回填**，`getById` 不要求（本期没有消费方）。若实现时顺手在 `getById` 也填了，属可接受的加法，但不得为此改动 `getById` 的既有返回。

-- Q0 全量
SELECT count(*) FROM quotation;
-- Q1 料号命中（把 :kw 换成小写关键字）
SELECT count(*) FROM quotation q WHERE EXISTS (
  SELECT 1 FROM quotation_line_item li WHERE li.quotation_id=q.id
    AND (LOWER(li.product_part_no_snapshot) LIKE '%'||:kw||'%'
      OR LOWER(li.customer_part_no)        LIKE '%'||:kw||'%'));
-- Q2 料号 ∧ 关键字 / Q3 料号 ∧ 状态 / Q8 料号 ∧ 分类 / Q9 料号 ∧ 分类 ∧ 状态：在 Q1 基础上追加对应 AND
-- Q4 模板下拉条目数
SELECT count(*) FROM template WHERE template_kind='QUOTATION' AND status='PUBLISHED';
-- Q5 指定分类 / Q6 未分类
SELECT count(*) FROM quotation WHERE product_category_id = :cid;
SELECT count(*) FROM quotation WHERE product_category_id IS NULL;
-- Q7 指定模板
SELECT count(*) FROM quotation q JOIN template t ON t.id=q.customer_template_id WHERE t.name=:tname;
-- Q10 料号 ∧ 销售员：Q1 追加 AND q.sales_rep_id=:uid
