🚫 实现时不许做的四件事

① 不许只显示一个号（哪怕「主要的那个」）—— 用户在报价行、BOM 页签、核价单上都会分别看到它们，这里瞒下会让他以为出了 bug。
② 不许用「产品料号 / 零件料号」之外的叫法（如「父料号 / 子料号」「主号 / 从号」）—— 那是实现视角，用户的心智模型是「产品」和「零件」。
③ 不许把「会被复用」写成承诺：文案是「用完全一样的零件会复用」，🚫 不是「以后都会复用」。复用判据在后端（D-2：品名/规格/材质完全相同），前端不许自己推导。
④ 不许在这里解释三层模型 —— 上面那棵小树是给「看一眼就懂」用的，🚫 不要配一段架构说明。

📌 两个颜色是刻意的

产品料号蓝、零件料号绿，并在全流程保持一致（卡片、BOM 页签、核价单）。 用户在别处再见到这两个号时，靠颜色就能对上这一屏，🚫 不要每个页面各挑一套颜色。
