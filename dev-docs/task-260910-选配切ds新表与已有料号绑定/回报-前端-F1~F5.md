## 6. 子代理规避掉的坑（7 条，逐字要点）

1. **`tsc --noEmit` 差点是空验证** —— 派工单写的是 `npx tsc --noEmit`；根 `tsconfig.json` 是 solution-style（`files:[]` + references），`tsc -p`（不带 `-b`）**不跟进 references ⇒ 编译 0 个文件、恒返 0**。改用 `tsconfig.app.json` + `tsconfig.test.json`，**并注入类型错误做证伪实验**确认真的在检查。
2. **满宽禁用按钮会静默塌成内容宽** —— `ReasonedButton` 的 tooltip 包裹层是 `display:inline-block`，里面 `width:100%` 无百分比基准 ⇒ 原型 01 第四态那颗满宽虚线按钮会缩成一小颗，**tsc 和 curl 都发现不了**。加了 `block` prop。
3. **删单值材质字段时差点留下兜底分支** —— 原 `row.recipeSymbol || …` 是 task-260902 的过渡逻辑；留着 = 后端多材质正常返回时**静默只显示一个**。
4. **绑定路径的确认页会说假话** —— 见 §1 的连带修正。结果页那处更隐蔽（`fingerprintMatched` 恒 false 且 `reusedHfPartNos` 为 `[]`，会落到「已新建一个销售料号」）。
5. **互斥只做单向 = 用户能走到 400** —— 已选绑定后可从「更换料号」→「上一步」→ 选零件，凑出 `bind + parts` 双非空。做成双向 + `upsertPart` 第三道防线 + submit 显式传 `parts: []`。
6. **没拿共享 5174 验证自己的改动** —— 用 5185 临时起、验完即停。
7. **grep 用 `/usr/bin/grep -a`** —— 本环境 `grep` 是 `ugrep -I`，会把中文注释密集的大文件静默判为二进制返空，这几个文件正好都是。
