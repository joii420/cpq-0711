## 实现约束

1. 所有 multipart 临时文件必须在请求线程读完，不将 `FileUpload` 对象或临时路径传入异步任务。
2. 统一处理服务的输入／输出字节不可变；下游需要流时从处理结果创建新流。
3. 使用 JDK/Quarkus 已有 HTTP 能力，如无必要不新增依赖；若确需改 `pom.xml`，先报主线，因为会扩大冷启动验证面。
4. 权限拦截必须早于文件安全处理；401/403 请求不可对外部服务产生流量。
5. 不在业务 Resource 中复制 HTTP 调用、错误映射、profile 判断或文件名编码逻辑。
6. 禁止记录完整文件名、令牌和任何文件内容；可记录 requestId、操作类型、字节数、耗时、上游 HTTP 状态和允许列表错误码。
7. 不新增 DB 迁移，不改变原导入业务校验的先后关系，除非为了保证密文不进入解析／落盘链路。
