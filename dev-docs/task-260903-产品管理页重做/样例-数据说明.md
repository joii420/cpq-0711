## 5. 数值与格式约定

| 项 | 做法 | 理由 |
|---|---|---|
| numeric 列 | 去掉 `numeric(26,12)` 的补零，写**最短等值表示**（`0.700000000000` → `0.7`） | 值不变，只去尾零；与 `原型图/销售产品-默认态.html` 显示的 `0.7` / `0.05` / `0.002` 一致 |
| integer 列（项次） | 写整数 | |
| 空值 | 写**空单元格**，不写 `''`、不写 `-`、不写 `NULL` 字样 | 空单元格才会被判为「未填」；写字符串会变成一个假值 |
| 字符串列 | 原样导出，不 trim、不改大小写 | |
| 标记行底色 | 灰色（仅为人眼可读） | 导入按**文字** `轴` / `对比项` 判定，底色不参与 |
