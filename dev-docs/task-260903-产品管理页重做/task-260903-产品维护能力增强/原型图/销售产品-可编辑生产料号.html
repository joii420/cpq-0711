⚠️ 四条实现纪律
1. 保存只传 { productionNo } —— 🚫 不要整行回传。后端只更新传入列，整行回传会把没改的列一起写。
2. 🚨 source 不传、也不要期望它变。它是行级来源（IMPORT/MANUAL），改一列就把整行标成 MANUAL 会误导 —— 该行绝大部分数据仍来自导入。AC-10 断言它保持 IMPORT。
3. 清空是合法操作（用户原话「生产料号选填」）：落库 NULL（不是空字符串），列表渲染 —。
　 ⚠️ 与导入的 COALESCE 区分：页面显式清空 ⇒ 真的变 NULL；导入时 Excel 空着 ⇒ 保留库里的值。两件事，别用同一条分支。
4. 保存失败要回滚到原值并提示，🚫 不许把失败的值留在界面上假装成功（状态 ④）。
