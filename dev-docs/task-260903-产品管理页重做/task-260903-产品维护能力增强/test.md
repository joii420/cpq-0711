## 5. 证伪实验（🚫 不做不算测完）

| # | 实验 | 判据 |
|---|---|---|
| **FS-1** | **编辑真的落库了吗** —— 改完值后**绕过页面**直接查库 | 库值必须等于新值。只看页面显示 = 可能只改了前端 state |
| **FS-2** | **白名单真的有牙吗** —— 把 `AC-11` 的请求改成传**白名单内**的 `productionNo` | 必须 **200 并生效**。若两种字段都 400，说明端点根本没工作，AC-11 的「400」是假通过 |
| **FS-3** | **过滤真的在后端做吗** —— 选 `CUST-0004` 时抓 Network | 请求须带 `customerNo` 参数且 `total` 直接是 11。若前端捞 17 行自己 filter，翻页会错 |
| **FS-4** | **AC-7 的只读断言有牙吗** —— 沿用父任务的 **FS-1a 阳性对照**：把同一个只读断言指向**核价侧**可编辑抽屉 | 必须**抛错**。父任务实证核价抽屉 `input=96 保存=1` |

> 🔬 **还原实验纪律**：自己写的验证脚本**首次 PASS 也可能是空验证**。把干预改回去重跑，**不变红 = 白测**。
