**用户裁决（2026-09-03）：走甲。**

**选甲的理由**：写入语义**保持单一来源**，仍归 `task-260902` 统一维护；三个数据集通用，将来同类需求不必再造端点；避免本任务的包里长出第二套写入逻辑、日后还要迁移合并。

**代价（已知并接受）**：要占对方排期，而它当前卡在 V409 + 等用户改三份 Excel ⇒ **S-1 的开工时间取决于对方**。
