## 3. 已知问题与偏差

| **K-1** | **多步 E2E 用例撞 `timeout: 30_000`** —— E2E-09（跨页面切角色）与 E2E-11（八步序列）在 30s 下必失败，`--timeout=150000` 后**双双通过** | ⚠️ **不是产品缺陷**。已用独立诊断脚本证伪「reload 后被弹回 /login」的猜测（实测 reload 后 URL 正确、tab 数=2、文案齐全）。**跑本 spec 必须显式放宽超时** |

| **K-3** | `assertIsolatedEnv` 要求同时给 `PW_BASE_URL` + `PW_BACKEND_URL`，缺一即硬失败 | ✅ **设计如此**，防止误跑在共享 5174/8081 挤占主线亲验环境。**主线本人第一次跑就被它拦住了** |
