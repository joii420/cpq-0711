## 2. 关键用例设计（只写非显然的）

### T-05 / T-07 三视图料号一致（需求 2 的主判据）

```
1. 打开 QT-20260825-0180 编辑页 → Step2 → 停在第 3 页
2. 卡片视图：抓取当前页所有卡片头部的生产料号 → 集合 A
3. 切「Excel 视图」：抓取表格所有行的生产料号 → 集合 B
4. 切「核价单」→「产品卡片」：抓取 → 集合 C
5. 断言 A == B == C（逐条比对，无多无少），且 |A| == 100
```
🚨 **T-07 必须单独断言 Excel 视图行数 == 100**。这是最容易漏的一条：
后端 `/excel-view` 全量返 1845 行，前端忘了切片时**卡片视图看着是对的**，只有 Excel 视图会露馅。

### T-09 查询命中深位料号

```
1. 先用 SQL 取出该单 sortOrder 第 1200 位的 productPartNo
2. 在查询框输入该料号完整值
3. 断言：命中计数 == 1，且该卡片渲染在第 1 页
```
> 判据要点：**必须选深位料号**。用第 1~100 位的料号测，即使实现只在当前页里找也会通过 —— **假绿**。

### T-15 冲突定位跨页（须造数）

```
1. 构造一个行键冲突，且冲突行落在第 17 页（sortOrder 第 1601~1700 区间）
2. 提交 → 冲突抽屉出现 → 点击该冲突项
3. 断言：页码自动切到 17，该卡片高亮可见
```

### T-19 性能五项（口径必须与基线一致，否则数字不可比）

| 指标 | 基线（实测） | 阈值 |
|---|---|---|
| JS 堆 used | 601.6 MB | **< 250 MB** |
| DOM 节点 | 146,231 | **< 15,000** |
| LayoutObjects | 138,686 | **< 15,000** |
| JS 事件监听器 | 24,626 | **< 3,000** |
| Step2 渲染耗时 | 32.0 s | **< 5 s** |

取数方式：CDP `Performance.getMetrics()`（`Nodes` / `LayoutObjects` / `JSEventListeners`）+ `performance.memory`。

### 🚨 T-20 泄漏护栏（本任务最容易被跳过、后果最严重）

```
1. 打开大单编辑页 Step2，强制 GC，记录四项指标 → 基线 M0
2. 依次翻到第 5 / 10 / 15 / 20 页，每次强制 GC 后记录 → M5 / M10 / M15 / M20
3. 回到第 1 页，强制 GC，记录 → M_end
4. 断言：M_end 与 M0 之差 ≤ 20%（GC 抖动容差），且 M5→M20 序列不得单调上升
```
> **为什么必须有**：实测事件监听器 **13.2 个/行**。卡片卸载时若未解绑，翻页会持续累积 ——
> **翻到第 18 页可能比不分页还糟，分页变成负优化**。
> ⚠️ 不达标 → **停下来报告，另立任务**。🚫 不许以"分页已让首页变快"为由放行。

### T-21 / T-23 A/B 对比手法

**同库背靠背**：同一张单，用 `git stash` 在「改动前 / 改动后」两个工作区状态各测一次，逐字节比对。
🚫 不许用「看起来差不多」判定。金额比对必须到**小数点后 12 位**。

### T-25 COMPOSITE（须造数，🚫 不许跳过）

> **现网全库 `composite_type` 均为 `SIMPLE`，零 COMPOSITE / 零 PART。**
> 缺数据的"未覆盖"**不等于**"已实现"。必须造一张含组合产品的单，

## 3. 已知假绿陷阱（照这个清单反查）

| # | 陷阱 | 反查方法 |
|---|---|---|
| 1 | 查询只在当前页找，用浅位料号测会通过 | T-09 强制用**第 1200 位**料号 |
| 2 | Excel 视图忘了切片，卡片视图看着正常 | T-07 **单独**断言 Excel 行数 |
| 3 | 泄漏被"首页变快"掩盖 | T-20 翻 20 页序列，不是只测第 1 页 |
| 4 | 总额误改成分页子集求和，小单上看不出来 | T-21 用**大单**做 A/B，比到 12 位小数 |
| 5 | COMPOSITE 断链因无数据而"测不出来" | T-25 强制造数 |
| 6 | 写路径下标用了页内下标（AP-54 复发） | 在第 **3 页**编辑一个单元格，断言写回的是该行而非第 3 页首行 |
| 7 | 测到了旧代码 | 每轮测试前确认 dev server 已热重载（改一行加 `console.warn` 验证生效） |
