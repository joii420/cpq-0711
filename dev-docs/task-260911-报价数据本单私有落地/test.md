## 4. 量具陷阱（本项目实证 + 本次评审新增，照抄执行）

| 陷阱 | 判据 |
|---|---|
| `curl` 探本机服务走系统代理返 502 | 一律加 `--noproxy '*'` |
| `/q/health` 返 404 不是健康探针 | 判后端健康看业务端点返 **401** |
| `curl` 返 `000` ≠ 进程已停 | **服务重启中同样返 000**（实证：8099 僵尸存活 8 小时） |
| `grep` 在本环境是 `ugrep -I`，中文注释多的文件**静默返空** | 一律 `/usr/bin/grep -a` 复核 |
| 表名拼字符串进 SQL ⇒ 按「表名位」正则命中为 0 | 搜写入点要同时搜常量清单（`T-5` 陷阱族） |
| 表格 DOM `innerText` **无分隔拼接**击穿词边界正则 | 按列取 `td` 或按下标定位 |
| 「进对了页面」≠「进对了视图」 | 核价单 review 页默认停在「报价单」分段 |
| `psql -t` 读回文本附尾部空白，往返漂移 1 字符且无感 | 改配置类数据要么库内 `replace()` 直改，要么**每次核对 md5** |
| 🆕 **`git diff --stat master...branch` 空输出 ≠ 分支没提交** | 它的真实含义是「**该分支内容已全部并入 master**」。判分支是否领先用 `git rev-list --count master..branch`（本次第一版就栽在这，评审 `F-3`） |
| 🆕 **「全部通过」的分母可能是 0** | `QuoteViewValidationService` 当前对每段都早退「不适用」⇒ `total` 恒 0 ⇒ 空跑却显示全过。**凡「全部 X 通过」的断言必须同时断言 `total > 0`**（评审 `F-4`） |
| 🆕 **共享库行数是移动靶** | 同一条 SQL 20 分钟内从 `41/95` 漂到 `55/146`。行数类数字**不许进断言**，只能进「量级参考」（评审 `F-9`） |
| 🆕 **javadoc 里的实测数字是写它那一刻的快照** | 第一版把 `DsRecordProjector` javadoc 里「9 行 NULL / 8 行 `QUOTE_BACKFILL`」当成现状，实查是 `1 / 0`（该缺陷早已修复）。**引用注释里的数字前先自己查一遍**（评审 `F-10`） |
