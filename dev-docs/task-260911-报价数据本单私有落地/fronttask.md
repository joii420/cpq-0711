### 🚨 为什么「补删除行清单」不能省（`AC-11③`）

`AP-60` / `repair-0727` 事故的核心症状是：**财务在预览里看到「新增 0 / 删除 0 / 改值 0」，执行后一个组从 4 行被删成 1 行。**

本任务推翻了 `D-34`「回填永不删行」⇒ 减行成为合法态 ⇒ 那条红色警示要摘掉。
**但摘掉告警而不装替代品，就是把唯一的哨兵撤了。** `BL-0211` 原文同样要求「将删除 N 行**单列出来**」。

⇒ 摘红色警示与补删除行清单是**同一批**，🚫 不许只做前半。
