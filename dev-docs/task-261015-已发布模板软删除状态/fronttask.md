# 前端任务

## F-1 模板列表状态与筛选（服务 AC-3、AC-9、AC-12）

- 增加 `DELETED` 类型、颜色和“已删除”标签。
- 默认列表不发送 `status=DELETED`；SYSTEM_ADMIN 可切换到“已删除”历史筛选并打开模板。
- 非管理员不显示已删除历史筛选入口；不通过隐藏普通按钮制造恢复能力。
- 已删除模板行不显示编辑、发布、归档、恢复等动作。

## F-2 删除与管理员创建新模板（服务 AC-1、AC-7、AC-8、AC-12）

- 继续使用顶部工具栏批量删除；PUBLISHED 行允许删除，DRAFT 保持原删除，ARCHIVED/DELETED 禁用并显示原因。
- 删除确认文案明确“仅改变模板状态，历史报价引用和快照不变”。
- SYSTEM_ADMIN 打开 DELETED 模板详情后显示“创建新模板”入口；调用现有 new-draft 接口后跳转新 DRAFT，不提供恢复按钮。

## F-3 报价模板选择回归（服务 AC-2、AC-5、AC-6、AC-11）

- 报价创建、复制、Excel 导入等选择器继续只请求 `PUBLISHED`。
- 已有 DRAFT 报价回显 DELETED 模板时保留原绑定显示，不把它当作可选候选。
- 不修改报价卡片、快照和只读渲染组件的数据结构。

## F-4 类型与交互测试（服务 AC-2、AC-3、AC-7、AC-9、AC-12）

- 更新 `TemplateData.status`、状态选项和相关映射。
- 覆盖管理员/非管理员列表、删除按钮禁用、历史查看、新建模板和错误提示。
- 本任务触发模板列表交互变更，原型基准见 `原型图/`。

## 前端不做

- 不新增独立页面，不改报价单编辑器布局，不改报价卡片渲染协议。
- 不提供 DELETED 模板恢复入口。
