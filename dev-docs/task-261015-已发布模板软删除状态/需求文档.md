> 角色口径：本任务将用户所说“管理员”按现有 RBAC 的 `SYSTEM_ADMIN` 解释；`SALES_MANAGER` 保持现有模板管理权限，但不能查看/复制 `DELETED` 模板。

> 2026-10-16 用户裁决补充：删除 `PUBLISHED` 模板开放给 `SALES_REP`、`SALES_MANAGER`、`PRICING_MANAGER`、`SYSTEM_ADMIN`；`DELETED` 仍不可恢复，查询、打开明细和创建新草稿仍仅 `SYSTEM_ADMIN`；模板管理列表移除“适用范围”列，范围筛选保留。

## ① 背景与目标

当前产品卡片模板只有草稿可物理删除，已发布模板只能归档。用户希望增加一个删除状态，让已发布模板可以从 `PUBLISHED` 转为 `DELETED`，删除后不能再被新的报价或产品模板绑定引用，并且默认模板列表不再查询该模板。

目标是把“业务上不再可用”和“历史数据仍可追溯”分开：删除状态不能继续参与新业务选择，但已生成的报价单、模板快照和历史引用不能因为模板被删除而失效。

## ② 范围

### 本期做

1. 评估并实现产品卡片模板状态 `PUBLISHED -> DELETED` 的完整状态语义。
2. 删除后的模板不再作为新报价模板、产品模板绑定或客户自动匹配的候选。
3. 默认模板列表不返回 `DELETED` 模板。
4. 保留历史模板记录、模板组件快照及报价单已有引用，保证历史报价仍可打开并按既有快照渲染。
5. 同步后端状态校验、数据库状态约束、前端状态展示/操作入口和跨模块回归测试。

### 本期明确不做

1. 不物理删除 `template` 记录、模板组件快照或报价单快照；物理删除的恢复/清理策略不在本期范围内。
2. 不改变报价单既有快照结构、价格计算、报价单绑定字段和历史数据内容。
3. 不修改独立的配置模板（`config_template` / `/config-templates`）状态体系；若需要同时支持该模块，另行扩范围裁决。
4. 是否允许删除后恢复、是否允许管理员显式查询 `DELETED`、以及已有草稿报价继续保存还是必须换模板，留到 A0 裁决，不在本文件中预设实现方案。

## ③ 验收标准（A0 前置口径）

以下为 A0 裁决后的最终验收口径。

### 单点

- **AC-1**：一条 `PUBLISHED` 产品卡片模板调用现有删除接口后返回成功，模板状态可观测为 `DELETED`，模板记录仍存在；即使已有报价引用，也不阻断状态变更。
- **AC-2**：`DELETED` 模板不能被新的报价创建、报价模板切换、产品模板绑定或客户自动匹配选中；接口返回明确的不可用错误。
- **AC-3**：不传状态的默认模板列表不返回 `DELETED`；`SYSTEM_ADMIN` 显式按 `status=DELETED` 查询时可看到已删除模板，非管理员不能使用该历史查询口径。
- **AC-4**：模板删除后，报价单的模板外键、模板状态、模板快照和报价卡片快照均不被删除或改写；报价单查询仍能带出原模板信息。

### 序列

- **AC-5**：发布模板 → 生成报价并打开卡片 → 将模板置为 `DELETED` → 再次打开原报价，原产品卡片结构、组件和值仍能渲染。
- **AC-6**：发布模板 → 删除模板 → 已绑定该模板的 DRAFT 报价继续按原模板保存成功；若尝试从其他模板切换到该 `DELETED` 模板，则被拒绝。
- **AC-7**：`SYSTEM_ADMIN` 打开已删除模板并执行“创建新模板”，得到独立的 `DRAFT` 新模板；源模板仍为 `DELETED`，不能被恢复或改回 `PUBLISHED/ARCHIVED`。

### 边界与反向

- **AC-8**：`DRAFT` 继续保持现有物理删除行为；`ARCHIVED`、`DELETED` 调用删除接口时拒绝；不存在模板返回 404；重复删除不能产生额外写入。
- **AC-9**：删除操作权限继续遵循现有模板管理角色；删除状态下的查看和“创建新模板”仅 `SYSTEM_ADMIN` 可执行，普通角色收到 403。
- **AC-10**：历史报价读取、报价卡片快照读取、Excel/PDF 相关读取路径把 `DELETED` 视为已冻结模板，不回落读取活组件表，也不报未冻结错误。
- **AC-11**：产品绑定、客户匹配、报价复制和新建报价等所有新引用入口均拒绝 `DELETED`，但已有引用记录不被清理。
- **AC-12**：模板列表状态标签、筛选、删除按钮和管理员历史查看入口与 `原型图/` 定稿一致；删除状态不出现编辑/恢复操作。

### 原型基准映射

- AC-3、AC-8、AC-12：对照 `原型图/模板列表-删除状态.html` 的默认列表、管理员历史筛选、空态和禁用态。
- AC-7、AC-9、AC-12：对照 `原型图/模板详情-删除状态.html` 的详情告警、管理员“创建新模板”按钮、恢复/编辑禁用态和 403 错误提示。

## ④ 依赖与影响面

- 数据库：`template.status` 当前 CHECK 约束只有 `DRAFT/PUBLISHED/ARCHIVED`；需要评估状态约束迁移。
- 模板服务：删除、列表、发布、归档、新建草稿、客户匹配和快照冻结相关逻辑均读取模板状态。
- 报价服务：新建/保存/复制报价共用模板绑定校验；历史草稿保存存在“当前模板值不变则放行”的既有语义，是否适用于 `DELETED` 需 A0 裁决。
- 产品绑定：`ProductTemplateBindingService` 当前只允许 `PUBLISHED` 模板，仍需验证删除状态下列表、默认绑定和历史绑定读取行为。
- 渲染链路：`PublishedTemplateReader`、`ConfigureSnapshotService`、`BomTreeRenderService`、`ExcelViewService` 等当前把 `PUBLISHED/ARCHIVED` 作为冻结状态判断；新增状态可能需要纳入历史快照读取语义。
- 前端：模板列表状态类型、标签、状态筛选和删除操作提示；报价模板选择器目前显式请求 `PUBLISHED`，仍需验证所有入口。
- 架构基线：涉及《三大核心模块基线》模板冻结与报价渲染快照契约；不得让 `DELETED` 回落读取活组件表，也不得删除历史快照。
