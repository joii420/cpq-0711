## 5. 🚨 三条防"假绿"要求（本任务最容易骗过自己的地方）

### ① AC-19/AC-20 必须做**还原实验**
回环测试首次 PASS **不等于**它真的在验东西。
⇒ 把「含量 ÷100」那行改回不除（或把只读列挪到第 1 列），**重跑 T-19/T-20**：
**必须变红**。不变红 = 这两条用例是空验证，重写。
（记忆教训：自己写的验证脚本首次 PASS 也可能什么都没验。）

### ② 权限用例必须验**两个方向**
只验"管理员能调通"不算数 —— 那在权限注解漏标时也会通过。
必须同时有「非管理员 → 403」的用例，且**先确认那个非管理员会话是真的登录成功了**（否则拿到的 401 会被误读成 403 的近似）。

### ③ 断言"文件内容"而非"请求成功"
`200 + 有 body` 不能证明导出对了。每条导出用例都必须**打开 xlsx 读单元格**再断言。
🚫 只断言 `response.status == 200` 或 `body.length > 0` 的用例，视为未覆盖。
