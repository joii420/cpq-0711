🚨 含量列必须是 0–1 小数，不是库里的百分数。库中 301/Cu/301 存的是 default_pct = 84 和 16， 导出必须写 0.84 / 0.16。因为导入端 pctInRange(v, 1) 只收 (0, 1] —— 照搬库值导出的文件，回导时每一行都会被判「含量非法」，这个功能就白做了。AC-5

组号：取 material_recipe_config.seq。它在导入侧只是「文件内给同一材质分组」的标签、不落库，所以导出时用 seq 填回去即可，回导后仍是同一组。

⚠
若导入的是「未筛选状态」导出的文件，其中已停用的材质会被新建为一条同名的启用材质。
需要原样回导时，请先在列表把「状态」筛为「启用」再导出。
为什么会这样：材质导入按 symbol AND status='ACTIVE' 匹配既有材质（task-260901 既有语义）。 停用材质（实测 SnO2-del / 00263）匹配不上 → 被当成新材质创建。
用户裁决（2026-09-02）：导出保持「所见即所得」不做过滤，也不改导入逻辑，改为在这里加提醒。 用户若不筛选就回导，导入报告的「新增材质」计数会显示出来，不是完全静默。
