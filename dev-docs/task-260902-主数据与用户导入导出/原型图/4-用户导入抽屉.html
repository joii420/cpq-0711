导入用户 · 抽屉

从用户管理页工具栏「导入用户」打开。形态与「导入材质库」抽屉保持一致（说明区 → 上传区 → 下载模板 → 底部动作），不另发明一套。

ⓘ
按 frontend.md §1.1：用抽屉不用弹窗。宽度取 640px，与材质导入抽屉同宽。

状态 A · 打开时（未选文件）默认

导入用户✕
ⓘ
模板列（6 列，单个工作表）：用户名  |  姓名  |  邮箱  |  角色  |  区域  |  部门
• 只新增，不修改 —— 用户名已存在的行整行跳过，不会覆盖现有用户的姓名/角色/部门
• 不填密码 —— 系统为每个新用户生成一个随机初始密码，导入完成后在结果页统一显示
• 角色填：系统管理员 / 销售经理 / 销售代表 / 财务（也接受 SYSTEM_ADMIN 等英文枚举）
• 区域 / 部门可留空；填了但系统里没有该名称时，该行仍会创建，只是这两个字段留空并在报告里提示
⇧
点击或拖拽 .xlsx 文件到此处
仅支持 .xlsx，单文件最大 20 MB
AC-14
