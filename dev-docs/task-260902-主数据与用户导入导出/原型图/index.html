✅ 三个页面共用的两条规则（写在这里避免各页各写一套）

规则内容
「没权限」= 不渲染材质/工序页签对非 SYSTEM_ADMIN，导出按钮整个不渲染，不是灰色禁用。
禁用态是在说「条件不满足，满足了就能点」；这里是「你这个角色没有这项能力」，画成禁用反而在暗示可以申请。AC-2
「没东西可导」= 禁用筛选结果 0 条时，导出按钮禁用 + tooltip，三页文案逐字相同：
当前筛选结果为 0 条，无可导出数据
「导入」按钮不跟着禁用 —— 空表最需要导入。AC-23
