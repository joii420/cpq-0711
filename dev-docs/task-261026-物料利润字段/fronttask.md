## 交互与边界

- 利润不是百分比，不追加 `%`；也不展示货币符号。
- 页面不得把后端字符串先转为 JavaScript `number`；编辑控件使用字符串模式，防止精度丢失。
- 空字符串归一为 `null`；无变化退出编辑时不发请求。
- 利润列与生产料号列均可编辑，但各用专用组件，避免泛化既有 `EditableProductionNoCell` 后扩大回归面。
- 非数字在前端阻止提交并留在编辑态；后端仍是最终校验防线。
- 四个现有角色都看到编辑能力，权限与通用 PUT 端点保持一致。
- 组件取数配置只做联调验证：不在前端新增 `MATERIAL/profit` 条件分支，不改存量已选列。
- 报价卡片只读报价行返回的 `profit` 快照；前端不得另调销售产品接口做实时回填，也不得在 `profit` 缺失时按料号兜底。
- 利润提示框始终渲染；历史行、基础利润空值、滚动发布期间旧接口未带字段都统一显示 `利润: -`。
- 新增行内存态的利润来自候选/选配响应，保存后以后端报价行快照为准；不得把字符串转成 JavaScript `number`。
