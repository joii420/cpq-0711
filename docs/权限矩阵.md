# 系统权限矩阵

生成日期：2026-10-11  
适用系统：CPQ 询报价系统

本文按当前前端菜单和后端 `@RoleAllowed` 注解汇总权限。菜单矩阵反映“用户能看到什么”，后端矩阵反映“接口实际允许什么”；两者不完全等价。

## 角色定义

| 角色编码 | 系统名称 | 说明 |
|---|---|---|
| `SALES_REP` | 销售代表 | 客户、产品、报价和日常业务操作 |
| `SALES_MANAGER` | 销售经理 | 销售业务管理、行业/组件/主数据维护 |
| `PRICING_MANAGER` | 定价经理（部分页面显示“财务”） | 核价、价格审核、定价配置和部分主数据维护 |
| `SYSTEM_ADMIN` | 系统管理员 | 系统配置、用户、权限相关管理和全量运维操作 |

## 隐藏或存在前后端差异的功能

1. **3D 选配相关菜单当前隐藏**：选配实例、开始选配、分享链接、客户线索、选配模板、特征库和 3D 源文件页面仍保留路由/页面代码；隐藏菜单不等于接口权限撤销，具备后端权限的用户可能仍可通过直接 URL 访问。
2. **选配模板管理路由保留但菜单隐藏**：前端配置中已注释菜单项，后端 `SelTemplateResource` 仍提供相应接口。
3. **报价单管理对定价经理隐藏**：前端菜单只给销售代表、销售经理和系统管理员显示；但后端报价资源的类级权限包含定价经理，定价经理仍可从核价相关页面进入报价详情。
4. **组件管理存在权限不对齐**：前端菜单只显示给销售经理和系统管理员，但部分 `ComponentResource` CRUD 接口的后端注解仍包含四种角色。
5. **权限校验是注解式、非全局默认拒绝**：`RoleFilter` 仅对带 `@RoleAllowed` 的资源执行角色校验；没有该注解的 API 会跳过该层角色检查。因此本表不能替代一次“所有 API 是否都显式标注权限”的安全审计。
